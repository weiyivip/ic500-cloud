# 核心字段用途指南

本文档详细说明核心字段在分析体系中的用途、适用场景和限制。

**目的**：防止LLM误用字段，确保每个字段用在正确的分析模块。

---

## 一、多周期特征（multi_period_features）

### 1. multi_period_features.180min（第一层：3小时周期）

**用途**：定大方向（趋势框架）

**字段**：
- `ma.alignment`：均线排列方向（bull/bear/mixed）
  - **用于**：判断长期趋势方向（权重35%）
  - **不可用于**：日内短线择时

- `macd.status`：MACD状态（bull/bear）
  - **用于**：验证3小时级别趋势
  - **不可用于**：单独决定开仓点

- `rsi.status`：RSI状态（overbought/oversold/normal）
  - **用于**：判断是否过度延伸
  - **不可用于**：逆势开仓（超买不等于做空）

---

### 2. multi_period_features.60min（第二层：60分钟周期）

**用途**：定中线方向（验证趋势）

**字段**：
- `ma.alignment`：均线排列方向
  - **用于**：验证3小时趋势是否一致（权重25%）
  - **不可用于**：决定最终开仓（必须结合3小时周期）

- `macd.status`：MACD状态
  - **用于**：判断中线趋势强度
  - **不可用于**：单独决定开仓（需结合其他周期）

---

### 3. multi_period_features.30min（第三层：30分钟周期）

**用途**：寻找入场区域（支撑压力验证）

**字段**：
- `band.position`：价格在布林带中的位置（0-100）
  - **用于**：判断价格是否接近边界（权重15%）
  - **不可用于**：单独判断趋势方向

- `rsi.value`：RSI值
  - **用于**：辅助判断超买超卖
  - **不可用于**：逆势交易信号（超买可能继续上涨）

---

### 4. multi_period_features.5min（第四层：5分钟周期）

**用途**：短线择时（寻找入场点）

**字段**：
- `ma.alignment`：均线排列
  - **用于**：判断短线趋势（权重15%）
  - **不可用于**：判断大方向（容易被噪音干扰）

- `macd.status`：MACD状态
  - **用于**：辅助确认入场时机
  - **不可用于**：单独决定开仓（必须等待更高级别趋势确认）

---

## 二、RSI 字段路径说明（重要）

JSON 中存在两种 RSI 字段，必须严格区分：

### 1. indicators.rsi14（分钟线聚合值）
- **路径**：`indicators.rsi14`
- **结构**：直接是数值（如 `59.1`）
- **用途**：判断整体 RSI 状态（日线级别分析）
- **示例**：`indicators.rsi14 = 59.1`

### 2. multi_period_features.Xmin.rsi（周期级别对象）
- **路径**：`multi_period_features.30min.rsi.value`、`multi_period_features.60min.rsi.value` 等
- **结构**：对象，包含 `value` 和 `status` 两个字段
  - `rsi.value`: RSI 值（0-100）
  - `rsi.status`: RSI 状态（overbought/oversold/normal）
- **用途**：判断特定周期的 RSI 状态（多周期分析）
- **示例**：`multi_period_features.30min.rsi.value = 81.4`

**禁止混用**：
- ❌ 错误：`indicators.rsi.value`（indicators 下没有 rsi 对象）
- ❌ 错误：`multi_period_features.30min.rsi14`（多周期下没有 rsi14 字段）

## 三、联合验证要求（Required Field Combinations）

### 原则说明

本节仅列出容易被模型误用或需要联合验证的字段。未列出的字段可按照 JSON_SCHEMA 和 TRADING_RULES 的定义正常使用，无需强制组合。

---

### 1. 多周期 MA 对齐（★★★★★）

**必须组合使用**：
- `multi_period_features.180min.ma.alignment`
- `multi_period_features.60min.ma.alignment`
- `multi_period_features.30min.ma.alignment`

**验证规则**：
- **禁止仅凭单一周期均线方向判断趋势**
- 趋势方向必须至少结合 180min、60min 和 30min 三个周期进行验证
- 若三者不一致，则视为趋势共振不足

**常见误用示例**：
- ❌ 错误：`60min.ma.alignment = "bull"` → 做多
- ✅ 正确：180min、60min、30min 均为 "bull" 且价格站稳关键均线 → 做多

---

### 2. 布林带位置（★★★★★）

**必须组合使用**：
- `database_data.daily_features.future.band.position`
- ATR（波动率，可参考 `multi_period_features.60min.band.strength`）
- RSI（动能，`multi_period_features.60min.rsi.value`）

**验证规则**：
- **Band Position 仅表示价格所在位置，不代表趋势强弱或反转信号**
- 必须结合 ATR 判断波动环境，并结合 RSI 判断动能状态后，方可作为交易依据

**常见误用示例**：
- ❌ 错误：`band.position = 85`（接近上轨）→ 直接做空
- ✅ 正确：`band.position = 85` + ATR 扩张 + RSI 超买 → 考虑做空

---

### 3. 成交量特征（★★★★★）

**必须组合使用**：
- `indicators.volume_ratio`（或 `multi_period_features.Xmin.volume`）
  - **注意**：`indicators.volume_ratio` 是实时量比（当前 K 线成交量/20根 K 线均值），盘中可能因盘整而出现 0.0 或极小值
  - **建议**：不要单独使用，必须结合 `oi_change` 判断资金流向
- `database_data.tick_analysis.oi_change`（持仓变化）

**验证规则**：
- **成交量放大但持仓未增加，不得认定为新增资金入场**
- 成交量变化必须结合持仓变化判断资金流向

**常见误用示例**：
- ❌ 错误：`volume_ratio = 1.8`（放量）→ 放量突破，做多
- ✅ 正确：`volume_ratio = 1.8` + `oi_change > 0`（持仓增加）→ 资金流入，考虑做多

---

### 4. MACD（三线组合）（★★★★★）

**必须组合使用**：
- `macd`（快线）
- `signal`（慢线）
- `hist`（柱体）

**验证规则**：
- **不得仅依据 Histogram（柱体）判断趋势或拐点**
- MACD、Signal 与 Histogram 必须联合分析

**常见误用示例**：
- ❌ 错误：`hist` 缩短 → 趋势反转
- ✅ 正确：`macd` 上穿 `signal` + `hist` 由负转正 → 金叉确认

---

### 5. 支撑压力位（★★★★☆）

**必须组合使用**：
- `support_resistance.supports` / `support_resistance.resistances`
- `price.current`
- ATR（波动率）

**验证规则**：
- **价格是否接近关键位，必须结合 ATR 判断距离，不得仅依据绝对点位判断"临近支撑"或"临近压力"**

**距离判断标准**：
- 距离支撑/压力位 < 0.1 ATR → 非常接近
- 距离支撑/压力位 0.1-0.2 ATR → 较接近
- 距离支撑/压力位 > 0.2 ATR → 不算接近

**常见误用示例**：
- ❌ 错误：距离支撑 25 点 → 已到支撑
- ✅ 正确：距离支撑 25 点，但 ATR = 220（25/220 = 0.11 ATR）→ 较接近，未到
- ✅ 正确：距离支撑 25 点，ATR = 18（25/18 = 1.39 ATR）→ 远超支撑

## 四、五维量化打分（composite_score）

**注意：这是独立于五层周期的评分系统**

### 字段：
- `total_score`：综合得分（0-100）
  - **用于**：判断市场状态（bull/bear/sideways）
  - **不可用于**：直接决定开仓点（必须结合五层周期）

- `market_type`：市场类型（bull/bear/sideways）
  - **用于**：确定交易策略（牛市做多、熊市做空、震荡市高抛低吸）
  - **不可用于**：单独决定仓位（必须结合风险控制）

- `dimensions.basis_index`：基差分析得分
  - **用于**：判断期货相对现货的估值
  - **不可用于**：短期交易信号（基差变化较慢）

- `dimensions.capital_flow`：资金流向得分
  - **用于**：判断主力资金动向
  - **不可用于**：日内短线交易（资金流向数据滞后）

---

## 四、双合约架构（holding_contract & spread）

### 1. holding_contract

**用途**：提供实际可操作的价格

**字段**：
- `price.current`：持有合约当前价格
  - **用于**：实际下单价格（滑点估算）
  - **不可用于**：技术分析（历史数据不完整）

- `open_interest`：持仓量
  - **用于**：判断流动性
  - **不可用于**：判断趋势方向（持仓量不等于方向）

### 2. spread

**用途**：主力合约与持有合约的基差转换

**字段**：
- `spread`：价差（点数）
  - **用于**：价格修正（持有合约价格 = 主力合约价格 - 基差）
  - **不可用于**：独立判断趋势（基差受多种因素影响）

- `volume_ratio`：流动性比率
  - **用于**：判断滑点风险（<0.3需减小仓位）
  - **不可用于**：交易信号

---

## 五、基差特征（basis_features）

### 字段：
- `current_basis`：当前基差
  - **用于**：判断期货相对现货的溢价/折价
  - **不可用于**：短线交易信号（基差变化较慢）

- `basis_percentile`：基差历史分位数（0-100）
  - **用于**：判断基差是否极端（>80或<20需关注）
  - **不可用于**：独立决定方向（必须结合价格趋势）

- `basis_level`：基差水平（high/medium/low）
  - **用于**：辅助判断估值
  - **不可用于**：单独决定开仓

---

## 六、Tick分析（tick_analysis）

### 字段：
- `oi_change`：持仓量变化
  - **用于**：判断多空力量变化
  - **不可用于**：单独判断方向（增仓不等于上涨，需结合价格位置）

- `buy_sell_ratio`：买卖比例
  - **用于**：判断盘口情绪
  - **不可用于**：决定开仓（Tick数据噪音大）

- `market_quality`：市场质量（trend/fake_breakout/oscillation）
  - **用于**：判断当前行情类型
  - **不可用于**：预测未来走势（仅描述当前状态）

---

## 七、简单字段（不需要详细用途说明）

以下字段用途明显，无需详细说明：
- **价格信息**（price.current, price.high, price.low）：基础行情数据
- **成交量**（volume.total）：基础行情数据
- **支撑阻力位**（support_resistance）：技术分析基础
- **估值特征**（valuation_features）：辅助判断估值水平
- **北向资金**（capital_flow.north_money）：辅助判断资金流向

## 八、常见误用警告

### 错误1：用短线指标判断长线趋势
```
错误：5min.macd.status = bear → 判断为空头趋势
正确：180min.ma.alignment + 60min.macd.status 判断趋势
```

### 错误2：单一指标决定开仓
```
错误：RSI超买 → 直接做空
正确：五层周期验证 + 五维评分 + 止损计算 → 决定开仓
```

### 错误3：忽视基差转换
```
错误：主力合约价格7600 → 建议开仓7600
正确：持有合约价格 = 主力合约价格 - 基差 = 7600 - (-10) = 7610
```

### 错误4：过度解读Tick数据
```
错误：buy_sell_ratio < 0.5 → 判断为空头趋势
正确：Tick数据噪音大，仅用于辅助判断盘口情绪
```

## 九、核心原则

1. **多周期验证**：必须结合至少3个周期（180min + 60min + 30min）
2. **多维度验证**：必须结合五维评分 + 五层周期
3. **禁止单一指标**：不得使用单一指标决定开仓
4. **尊重权重**：按照权重使用各周期（180min: 35%, 60min: 25%, 30min: 15%, 5min: 15%, Tick: 10%）
5. **冲突处理**：当五维评分与五层周期方向冲突时
   - 方向判断：五层周期优先（技术分析更可靠）
   - 仓位控制：参考五维评分（量化市场状态）
   - 禁止：五维评分覆盖五层周期方向
6. **证据约束**（Evidence Constraint）：任何交易建议必须引用至少4个不同类型字段
   - 技术字段（至少2个）：多周期趋势、价格位置、量价关系
   - 资金字段（至少1个）：持仓变化、资金流向、成交量
   - 风控字段（至少1个）：止损计算、流动性、到期风险

## 十、外盘数据（intl_market_quotes）

### 数据说明

**数据来源**：TqSDK外盘行情（延时15分钟）

**采集时间**：每天08:00（北京时间）

**数据时效性**：
- **盘中分析**（09:30-15:00）：✅ 可用（开盘前采集）
- **盘后分析**：✅ 可用（全天有效）

**核心用途**：
- A股开盘前预判（09:00-09:30）
- 隔夜全球市场情绪参考
- 外资态度判断

---

### 1. A50指数（intl_market_quotes.a50）

**用途**：A股开盘前最直接的参考指标

**字段**：
- `change_pct`：涨跌幅（%）
  - **用于**：预判A股开盘方向
  - **判断标准**：
    - >0.5%：A股大概率**高开**
    - <-0.5%：A股大概率**低开**
    - 其他：A股**平开**
  - **权重**：开盘前预判权重的50%

- `amplitude_pct`：振幅（%）
  - **用于**：判断A50波动强度
  - **判断标准**：
    - >2%：高波动（风险较大）
    - <1%：低波动（相对稳定）

- `gap_pct`：开盘跳空幅度（%）
  - **用于**：判断A50开盘情绪
  - **判断标准**：
    - >0.3%：强势开盘（看多情绪）
    - <-0.3%：弱势开盘（看空情绪）

**不可用于**：
- 盘中实时交易决策（仅用于开盘前预判）
- 替代技术分析（外盘数据是辅助参考）

---

### 2. 港股恒指（intl_market_quotes.hsi）

**用途**：外资对A股的态度判断

**字段**：
- `change_pct`：涨跌幅（%）
  - **用于**：判断外资整体态度
  - **判断标准**：
    - >0%：外资看好A股
    - <-0.5%：外资看空A股
    - 其他：中性态度
  - **权重**：开盘前预判权重的20%

**注意**：
- 08:00采集的数据是**前一日收盘数据**
- 主要用于判断外资态度，不用于精确预判

---

### 3. 美股指数（intl_market_quotes.sp500/nasdaq/dow/russell2000）

**用途**：隔夜全球市场情绪参考

**字段**：
- `sp500.change_pct`：标普500涨跌幅（%）
  - **用于**：美股大盘走势参考
  - **权重**：开盘前预判权重的15%

- `nasdaq.change_pct`：纳斯达克涨跌幅（%）
  - **用于**：科技股走势（对IC成长股影响大）
  - **权重**：开盘前预判权重的10%

- `russell2000.change_pct`：罗素2000涨跌幅（%）
  - **用于**：小盘股风险偏好（与IC相关性高）
  - **权重**：开盘前预判权重的5%

**注意**：美股在北京时间凌晨04:00收盘，08:00采集时已收盘4小时。

---

### 4. 汇率数据（intl_market_quotes.usdcnh/dxy）

**用途**：汇率对A股的影响

**字段**：
- `usdcnh.change_pct`：离岸人民币涨跌幅（%）
  - **正值**：人民币贬值（利空A股）
  - **负值**：人民币升值（利好A股）
  - **权重**：开盘前预判权重的5%

- `dxy.change_pct`：美元指数涨跌幅（%）
  - **用于**：美元强弱对全球资产配置的影响

---

### 5. 使用场景

#### 开盘前分析（09:00-09:30）

**必须使用**：外盘数据是开盘前分析的核心依据

**综合判断方法**：
```
1. A50涨跌幅 + 港股涨跌幅 → 判断开盘方向
   - A50 >0.3% + 港股 >0% → A股偏多
   - A50 <-0.3% + 港股 <-0.3% → A股偏空
   - 其他 → A股震荡

2. 美股走势 + 罗素2000 → 判断风险偏好
   - 美股涨 + 罗素涨 → 小盘股风险偏好高（利好IC）
   - 美股跌 + 罗素跌 → 小盘股风险偏好低（利空IC）

3. 人民币汇率 → 判断资金流向
   - 人民币升值 → 资金流入预期（利好A股）
   - 人民币贬值 → 资金流出压力（利空A股）
```

---

#### 盘中分析（09:30-15:00）

**辅助使用**：外盘数据不作为核心决策依据

**使用场景**：
- 验证开盘预判的准确性
- 监控A50日盘走势（A50在A股交易时段继续交易）
- 调整风险偏好（如美股夜盘走势突变）

**禁止**：
- 用外盘数据替代技术分析
- 用外盘数据决定盘中交易方向
- 忽视实时数据（multi_period_features、tick_analysis）

---

### 6. 数据限制

**延时15分钟**：TqSDK外盘数据有15分钟延时
- 开盘前分析：影响不大（主要看夜盘整体走势）
- 盘中分析：不适合高频交易

**数据完整性**：
- 港股09:30开盘，08:00采集时为前一日收盘数据
- 美股凌晨04:00收盘，08:00采集时已收盘4小时
- A50几乎24小时交易，数据最完整

**不提供实时推送**：外盘数据每天采集一次，盘中不更新

---

### 7. 常见误用警告

#### 错误1：用外盘数据替代技术分析
```
错误：A50涨0.5% → 盘中做多
正确：开盘前预判 + 盘中技术分析验证 → 决定交易
```

#### 错误2：忽视外盘数据的时效性
```
错误：盘中14:00还在使用08:00采集的港股数据
正确：港股数据仅供开盘前参考，盘中不更新
```

#### 错误3：过度依赖外盘数据
```
错误：A50涨 + 港股涨 → 必定做多
正确：外盘数据是辅助参考，必须结合技术分析和资金流向
```

### 8. 与其他数据的关系

**外盘数据 vs 技术分析**：
- 外盘数据：开盘前预判（辅助）
- 技术分析：盘中决策（核心）

**外盘数据 vs 资金流向**：
- 外盘数据：全球市场情绪（宏观）
- 资金流向：国内资金态度（微观）

**外盘数据 vs 五维评分**：
- 外盘数据：开盘前参考（Priority 4）
- 五维评分：交易决策（Priority 5）

### 9. 核心原则

1. **开盘前优先**：外盘数据主要用于开盘前预判，不用于盘中交易
2. **A50核心**：A50是最重要的外盘指标（权重50%）
3. **辅助定位**：外盘数据是辅助参考，不替代技术分析
4. **时效性**：盘中分析时，外盘数据仅供参考，不作为决策依据
   - 证据不足：输出"证据不足，维持观望"
