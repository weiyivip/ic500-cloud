# IC500 日内短线趋势判断与执行方案

## 定位

本技能是 `ic500-futures-analysis` 的**顶层执行层**，整合三个现有技能的核心能力，产出**完整的趋势裁决 + 可执行交易方案**：

| 来源技能 | 复用内容 | 本技能升级点 |
|----------|----------|-------------|
| `ic500-futures-analysis` | 五层周期 + 五维评分 + 风控铁律 + 数据格式 | 整合为四维趋势裁决矩阵 |
| `ic500-short-term-trading` | 交易方案模板 + 持仓管理 + 减仓决策树 | 升级为六种市场状态分类执行 |
| `ic500-review` | 趋势预判 + 自检清单 + 复盘框架 | 合并为日终复盘→次日计划桥接 |

> **必须先加载 `ic500-futures-analysis`** 获取底层数据格式、字段说明、时间路由与风控铁律。本技能不重复底层规则，只负责"把四维数据转化为趋势裁决 + 执行方案"。

## 两种运行模式

### 模式 A：日内实时模式（盘中 09:30-15:00）
**触发词**：「日内趋势」「盘中策略」「现在怎么做」「短线方案」「趋势判断」
**产物**：趋势裁决 + 执行方案（入场/止损/止盈/仓位/时间窗口）+ 持仓管理指令

### 模式 B：隔日预判模式（盘后 15:00 后 / 次日开盘前）
**触发词**：「次日计划」「隔日预判」「明日策略」「盘后复盘」「趋势预判」
**产物**：今日复盘 + 次日趋势预判 + 开盘场景化预案 + 执行方案

## 核心流程：六步法

### Step 1：数据获取与时段路由

1. 下载最新 `live_summary.json`
2. 读取 `timestamp` 确定当前时段（北京时间 UTC+8）
3. 时段路由：

| 时段 | 模式 | 执行重点 |
|------|------|----------|
| 09:30-11:30 | 日内实时 | 定基调 + 首笔交易窗口 |
| 11:30-13:00 | 午休预判 | 上午复盘 + 下午方案 |
| 13:00-14:30 | 日内实时 | 趋势确认 + 持仓管理 |
| 14:30-14:40 | 尾盘限仓 | 仅顺势强信号，禁止新仓 |
| 14:40-15:00 | **硬锁** | **强制观望，仅允许平仓** |
| 15:00 之后 | 隔日预判 | 复盘 + 次日计划 |

### Step 2：趋势裁决（Trend Verdict）

**四维合一**，输出单一方向裁决。详见 `references/trend_verdict.md`。

| 维度 | 数据来源 | 权重 | 作用 |
|------|----------|------|------|
| 日线大背景 | `database_data.daily_features` | 30% | 定多日趋势基调 |
| 五层周期 | `multi_period_features` | 35% | 定日内方向 |
| 五维评分 | `composite_score` | 15% | 定市场状态（仓位参考） |
| Tick盘口 | `tick_analysis` | 20% | 验证信号真实性 |

**裁决输出**：
```
趋势裁决：【做多 / 做空 / 观望】
置信度：【高 / 中 / 低 / 证据不足】
市场状态：【趋势上涨 / 趋势下跌 / 震荡 / 超买回调 / 超卖反弹 / 陷阱行情】
理由链：[4+ 项证据，2 技术 + 1 资金 + 1 风控]
```

### Step 3：市场状态分类

根据趋势裁决结果，将当前市场归入六种状态之一，每种状态对应特定执行策略。详见 `references/execution_playbook.md`。

| 状态 | 特征 | 执行策略 |
|------|------|----------|
| 趋势上涨 | 五层多头共振 + 量价配合 | 顺势做多，回踩加仓 |
| 趋势下跌 | 五层空头共振 + 量价配合 | 顺势做空，反弹加仓 |
| 震荡 | 五维评分 40-69 + 方向不一致 | 区间两端操作 |
| 超买回调 | RSI>70 + 多周期超买 | 禁止追多，等回调 |
| 超卖反弹 | RSI<30 + 极端超卖 | 可博反弹，严控止损 |
| 陷阱行情 | fake_breakout 持续 + OI 减 | 禁止追突破，只做回踩 |

### Step 4：执行方案生成

每个方案必须包含完整要素：
```
方向：多 / 空
市场状态：[Step 3 分类]
入场价：XXXX（当前价 / 回踩价 / 突破回确认价）
止损价：XXXX（固定 XX 点【因 ATR 口径异常】或 ATR 动态止损）
目标1：XXXX（XX 点，减仓 50%）
目标2：XXXX（XX 点，清仓）
盈亏比：XX/XX = X.XX（必须 >= 方案类型最低盈亏比）
仓位：X 手（根据置信度：高=2手 / 中=1手 / 低=0.5手 / 不足=观望）
时间窗口：HH:MM-HH:MM
失效条件：价格触及 XXXX 或 时间超过 HH:MM
逻辑链：至少 4 项证据（2 技术 + 1 资金 + 1 风控）
```

### Step 5：持仓管理

若已有持仓，执行动态管理。详见 `references/execution_playbook.md` 持仓管理章节。

**核心规则**：
- 浮盈 10-20 点 → 止损上移至保本位
- 浮盈 20+ 点 → 止损上移至保本+5 点
- `order_imbalance` 反转 → 立即减仓 50%，**命令式语气**
- 14:20 → 全部开始平仓
- 14:30 → **绝对退出线**
- 14:40 → 硬锁，系统强制观望

### Step 6：日终复盘 + 次日计划（盘后模式）

详见 `references/daily_workflow.md`。

1. 今日行情定性（趋势/震荡/陷阱）
2. 趋势裁决准确率回看
3. 执行方案盈亏统计
4. 次日趋势预判（基于日线特征 + 五层周期收盘状态）
5. 次日开盘场景化预案（高开/低开/平开）
6. 自检清单（7 项强制核对）

## 铁律（继承自下层技能，不可破）

1. **尾盘硬锁**：14:40-15:00 强制观望，绝对禁止新仓（Priority 0）
2. **双一票否决**：禁止交易条件（P1）+ 信号验证>=3 项（P2），任一不满足 → 观望
3. **ATR 口径异常**：`indicators.atr.value` 偏小（6-16 点）与实际波动（日内 100-200 点）不符 → 固定止损 25-30 点（趋势 30-40），显式标注【因 ATR 字段口径异常启用固定点数止损】
4. **方向一致性**：趋势裁决确定方向后，同一交易时段内不因短期数据波动反转，如需转向必须走完整流程
5. **建议明确性**：禁止"方案 A...但不建议"的模糊输出，每个建议必须是明确开仓/明确观望/条件触发之一
6. **利润锁定**：`sell_heavy` 环境下反弹超 20 点 → **立即减仓 50%，不商量**
7. **证据约束**：任何交易建议必须引用至少 4 个不同类型字段（2 技术 + 1 资金 + 1 风控），否则输出"证据不足，维持观望"
8. **五层优先**：方向听五层周期，仓位参考五维评分，五维不得覆盖五层方向
