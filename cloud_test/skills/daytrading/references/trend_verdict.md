# 四维趋势裁决系统

## 概述

本系统将四个维度的数据整合为**单一趋势裁决**，解决多维度信号冲突时"听谁的"问题。

---

## 一、四维输入定义

### 维度 1：日线大背景（权重 30%）

**数据来源**：`database_data.daily_features`

**判定规则**：

| 条件 | 日线判定 | 方向 |
|------|----------|------|
| MA5 > MA10 > MA20 > MA60 + MACD bull + RSI > 50 | 多头排列 | 偏多 |
| MA5 < MA10 < MA20 < MA60 + MACD bear + RSI < 40 | 空头排列 | 偏空 |
| 均线交叉 + 方向不一致 | 混合排列 | 中性 |
| MA5 < MA10 < MA20 < MA60 + RSI < 30 | 空头排列 + 极端超卖 | 偏空但注意反弹 |

**关键字段**：
- `daily_features.future.ma.alignment`：bear/bull/mixed
- `daily_features.future.macd.status`：bull/bear
- `daily_features.future.rsi.value`：RSI 数值
- `daily_features.future.band.position`：布林带位置（0-100）
- `daily_features.future.band.trend`：downtrend/uptrend

**特殊规则**：
- 日线空头排列 + 当日大涨（>2%）→ 标记为【熊市反弹】，日线维度仍判偏空，但叠加反弹预警
- 日线 RSI < 20 → 标记为【极端超卖】，即使空头排列也给 30% 反弹权重
- 日线布林带位置 < 20% + downtrend → 接近下轨，可能技术性反弹

---

### 维度 2：五层周期（权重 35%）

**数据来源**：`multi_period_features`

**五层权重**（固定不可逆）：

| 层级 | 周期 | 权重 | 核心字段 |
|------|------|------|----------|
| 第一层 | 180min | 35% | `ma.alignment`, `macd.status` |
| 第二层 | 60min | 25% | `ma.alignment`, `macd.status` |
| 第三层 | 30min | 15% | `ma.alignment`, `macd.status`, `rsi.value` |
| 第四层 | 5min | 15% | `ma.alignment`, `macd.status` |
| 第五层 | Tick | 10% | `tick_analysis.oi_trend`, `buy_sell_ratio` |

**五层综合判定**：

| 共振条件 | 五层判定 | 信号强度 |
|----------|----------|----------|
| 4 层 MA 同方向 + 3 层 MACD 同方向 | 强共振 | 极强 |
| 3 层 MA 同方向 + 2 层 MACD 同方向 | 中共振 | 强 |
| 2 层 MA 同方向 + 1 层 MACD 同方向 | 弱共振 | 中 |
| < 2 层同方向 | 无共振 | 弱（观望） |

**周期优先级**：180min > 60min > 30min > 5min > Tick
- 大周期方向优先于小周期
- 小周期与大周期背离 → 警惕转折，但不改变大周期方向判断

---

### 维度 3：五维评分（权重 15%）

**数据来源**：`composite_score`

**评分判定**：

| 总分 | 市场类型 | 方向偏置 | 仓位参考 |
|------|----------|----------|----------|
| 0-39 | 纯空头 | 偏空 | 0.5 倍标准仓位 |
| 40-69 | 震荡双向 | 中性 | 标准仓位 |
| 70-100 | 纯多头 | 偏多 | 1.5 倍标准仓位 |

**冲突规则**：
- 五维评分方向 ≠ 五层周期方向 → **方向听五层，仓位听五维**
- 禁止五维评分覆盖五层周期方向

---

### 维度 4：Tick 盘口验证（权重 20%）

**数据来源**：`tick_analysis`

**验证维度**：

| 字段 | 判定 | 信号 |
|------|------|------|
| `market_quality` | `fake_breakout` | 陷阱警告，禁止追突破 |
| `market_quality` | `active_attack` | 主动攻击，可顺势跟进 |
| `market_quality` | `passive_close` | 被动平仓，反弹不可持续 |
| `oi_trend` | `increase` + 价格涨 | 多头主动进攻 |
| `oi_trend` | `increase` + 价格跌 | 空头主动攻击 |
| `oi_trend` | `decrease` + 价格涨 | 空头平仓（假反弹） |
| `oi_trend` | `decrease` + 价格跌 | 多头止损（假下跌） |
| `buy_sell_ratio` | > 0.65 | 买盘强势 |
| `buy_sell_ratio` | 0.45-0.65 | 中性偏强 |
| `buy_sell_ratio` | < 0.45 | 卖盘主导 |
| `buy_sell_ratio` | < 0.35 | 卖盘极强，禁止做多 |

**Tick 验证作为否决项**：
- `market_quality = fake_breakout` 持续 → 否决追突破方案
- `oi_trend = decrease` + 价格涨 → 否决"新多入场"判断（标记为空头平仓反弹）
- `buy_sell_ratio < 0.35` → 否决做多方案

## 二、趋势裁决矩阵

将四维输入代入矩阵，输出单一裁决。

### 裁决矩阵

| 日线大背景 | 五层周期 | 五维评分 | Tick 验证 | 趋势裁决 |
|-----------|----------|----------|-----------|----------|
| 偏多 | 强共振多 | >70 | active_attack + OI 增 | **做多（高置信）** |
| 偏多 | 中共振多 | 40-69 | 买盘偏强 | **做多（中置信）** |
| 偏多 | 弱共振 | 40-69 | 中性 | **观望** |
| 偏空 | 强共振空 | <40 | active_attack + OI 增 | **做空（高置信）** |
| 偏空 | 中共振空 | 40-69 | 卖盘主导 | **做空（中置信）** |
| 偏空 | 弱共振 | 40-69 | 中性 | **观望** |
| 偏空 | 强共振多 | >70 | OI 减 + 价格涨 | **观望（熊市反弹，OI 减=假反弹）** |
| 偏空 | 中共振多 | 40-69 | fake_breakout | **观望（陷阱行情）** |
| 偏空 | 中共振空 | <40 | OI 减 + 价格跌 | **观望（多头止损，可能反弹）** |
| 偏空 + RSI<20 | 任意 | 任意 | 任意 | **超卖反弹做多（低置信，严控止损）** |
| 中性 | 强共振多 | >70 | active_attack | **做多（中置信）** |
| 中性 | 强共振空 | <40 | active_attack | **做空（中置信）** |
| 中性 | 弱共振 | 40-69 | 中性 | **观望** |
| 任意 | 任意 | 任意 | fake_breakout 持续 | **降级处理（陷阱行情）** |

### 特殊裁决规则

1. **熊市反弹识别**：日线空头排列 + 日内大涨 + OI 减少 → 标记【熊市反弹】，裁决降级一级（高→中，中→低）
2. **极端超卖覆盖**：日线 RSI < 20 → 无论五层方向，给"超卖反弹做多"方案（低置信，止损 20 点，目标 30-50 点）
3. **陷阱行情否决**：`fake_breakout` 持续 2 小时以上 → 所有追突破方案降级为观望
4. **OI 背离否决**：OI 减少 + 价格涨 → 不得裁决为"趋势上涨"，标记为"空头平仓反弹"

## 三、冲突处理规则

### 冲突场景 1：日线 vs 五层周期

| 日线 | 五层 | 处理 |
|------|------|------|
| 偏多 | 偏空 | **五层优先**（日内交易以五层为准），但标注"日线与日内方向背离" |
| 偏空 | 偏多 | **五层优先**，但标注"熊市反弹"，降级置信度，收紧目标点数 |

### 冲突场景 2：五维评分 vs 五层周期

| 五维 | 五层 | 处理 |
|------|------|------|
| >70（多头） | 偏空 | **方向听五层**（做空），仓位减半（0.5 倍） |
| <40（空头） | 偏多 | **方向听五层**（做多），仓位减半（0.5 倍） |

### 冲突场景 3：Tick vs 五层周期

| Tick | 五层 | 处理 |
|------|------|------|
| fake_breakout | 偏多 | **Tick 否决**，降级为观望或只做回踩 |
| OI 减 + 涨 | 偏多 | **标记假反弹**，降级置信度，目标收紧至 30 点 |
| buy_sell_ratio < 0.35 | 偏多 | **Tick 否决**，禁止做多 |

## 四、置信度计算

### 置信度评分表

| 维度 | 高分（+1） | 中分（+0.5） | 低分（0） | 否决（-1） |
|------|-----------|-------------|----------|-----------|
| 日线大背景 | 方向一致 | 中性 | 方向背离 | - |
| 五层周期 | 4+ 层共振 | 3 层共振 | <3 层 | 无共振 |
| 五维评分 | 方向一致 | 中性（40-69） | 方向背离 | - |
| Tick 验证 | active_attack | 中性 | fake_breakout | OI 背离 |

### 置信度判定

| 总分 | 置信度 | 建议仓位 |
|------|--------|----------|
| >= 3.0 | 高 | 2-3 手 |
| 2.0-2.5 | 中 | 1 手 |
| 1.0-1.5 | 低 | 0.5 手 |
| < 1.0 | 证据不足 | **强制观望** |

### 证据数量约束

| 置信度 | 最低证据数 | 信号验证 |
|--------|-----------|----------|
| 高 | >= 8 项 | >= 5/5 通过 |
| 中 | 5-7 项 | >= 3/5 通过 |
| 低 | 4 项（最低） | >= 3/5 通过 |
| 不足 | < 4 项 | 强制观望 |

## 五、趋势反转判定

### 反转触发条件（满足 >= 2 项）

1. **MACD 交叉**：五层中至少 2 层 MACD 发生金叉/死叉
2. **均线排列变化**：180min 或 60min 的 `ma.alignment` 从 bull 变 bear（或反向）
3. **OI 方向反转**：`oi_trend` 从 increase 变 decrease（或反向）+ 价格方向同步变化
4. **RSI 极值回归**：RSI 从 > 80 回落至 < 60，或从 < 20 反弹至 > 40
5. **market_quality 切换**：从 fake_breakout 切换为 active_attack（或反向）

### 反转处理流程

1. 确认反转条件（>= 2 项满足）
2. 显式说明"原方向判断需要修正的原因"
3. 重新走完整四维裁决流程
4. 生成新方向执行方案
5. 止损必须收紧至 20 点以内（反转初期波动大）

### 反转禁止场景

- 14:00 后不允许反转开新仓（时间不足）
- `fake_breakout` 持续期间的反转信号视为假信号
- 单一维度变化不构成反转（必须 >= 2 维度确认）

## 六、OI 阈值信号层

基于 2026-08-06 实战验证，OI 变化百分比是反弹/下跌的关键触发信号，单独列为信号层补充四维裁决。

### OI 临界值判定

| OI 变化% | 阶段 | 信号 | 操作建议 |
|----------|------|------|----------|
| > -5% | 正常波动 | 无信号 | 正常交易 |
| -5% ~ -7.5% | 空头回补初期 | 谨慎信号 | 空单收紧止损至保本位 |
| -7.5% ~ -9% | 空头回补尾声 | **反弹触发信号** | **空单减仓 50%** |
| < -9% | 空头回补高峰 | 极端信号 | 禁止追空，等反弹 |
| 收窄速度 > 5%/h | 加速收窄 | 尾盘反弹预警 | 14:00 前空单全部退出 |

### OI 阈值反弹触发规则

1. **触发条件**：OI 从 < -9% 收窄至 -7.5% 附近
2. **反弹概率**：> 70%
3. **反弹幅度**：25-35 点（基于 2026-08-06 实战数据）
4. **伴随特征**：`order_imbalance` 从 sell_heavy 转向 buy_heavy
5. **持续时间**：30-60 分钟
6. **操作指令**：持仓空单立即减仓 50%，命令式语气，不商量

### OI 阈值与四维裁决的交互

- OI 阈值信号不改变趋势裁决方向，但**强制触发持仓管理指令**
- 即使四维裁决仍为做空，OI 收窄至 -7.5% 时必须执行空单减仓
- OI 阈值信号作为 Tick 盘口验证（维度 4）的子项，增强 Tick 维度的判定精度

## 七、多周期 RSI 极值背离

不同周期 RSI 出现极值背离时，是趋势衰竭或假信号的强烈预警。

### 背离类型与判定

| 背离类型 | 识别条件 | 含义 | 操作 |
|----------|----------|------|------|
| 短超卖+长超买 | 5min RSI < 20 + 60min RSI > 75 | 短期超卖但大周期仍超买，下跌是回调非反转 | **禁止追空** |
| 短超买+长偏弱 | 5min RSI > 80 + 60min RSI < 50 | 短期超买但大周期仍弱势，上涨是反弹非反转 | **禁止追多** |
| 全周期超买 | 5min + 30min + 60min RSI 全 > 70 | 极端超买，回调 imminent | 做多方案降级，准备做空 |
| 全周期超卖 | 5min + 30min + 60min RSI 全 < 30 | 极端超卖，反弹 imminent | 做空方案降级，准备做多 |
| RSI 暴涨 | 2 分钟内 RSI 上升 > 20 | 空头集中平仓，反弹剧烈但不可持续 | 持仓空单立即平仓 |

### RSI 背离与趋势裁决的交互

- 短超卖+长超买背离 → 趋势裁决做空置信度降一级
- 短超买+长偏弱背离 → 趋势裁决做多置信度降一级
- RSI 暴涨 > 20/2min → **强制平仓指令**（无论方向），优先于所有持仓管理规则
- 全周期极值 → 触发反转判定流程（见第五节）

### 实战验证

**2026-08-06**：
- 13:20 出现短超卖+长超买背离：5min RSI = 19.8（极端超卖），60min RSI = 75+（超买）
- 判定：下跌是回调非反转，禁止追空
- 随后价格从 7683 反弹至 7711（+28 点），验证判断
- 13:32 RSI 2 分钟暴涨 24 点（19.8 → 43.6），触发强制平仓指令
- 持仓空单在 7687 果断平仓，锁定 +30 点利润
- 教训：RSI 极值背离 + RSI 暴涨 = 反弹剧烈但不可持续，必须立即平仓保利润

## 八、薄流动性修正因子

基于 2026-08-07 实战验证，薄流动性环境下所有技术信号可信度显著下降，需引入修正因子对四维裁决结果进行校正。

### 流动性对信号可信度的影响

| `spread.volume_ratio` | 流动性等级 | 信号可信度修正 | 操作建议 |
|----------------------|------------|----------------|----------|
| > 0.05 | 正常 | 0%（原始信号） | 正常执行 |
| 0.03-0.05 | 偏低 | -10%（信号强度减弱 10%） | 仓位减半 |
| < 0.03 | 极薄 | **-20%（信号强度减弱 20%）** | **仅最强信号操作，仓位 1/3** |

### 修正方法

当 `volume_ratio` < 0.03 时：

1. **MACD 交叉信号延迟确认**：所有 MACD 金叉/死叉信号需等待 2 根 K 线确认（防止零量假信号）
2. **RSI 超买/超卖阈值调整**：超买从 70 调整为 65，超卖从 30 调整为 35（提前触发保护）
3. **支撑阻力有效性降低**：突破需 2 倍确认量方可采信
4. **止损宽度增加 50%**：例如趋势单止损从 30 点 → 45 点
5. **sell_heavy 信号反转**：薄流动性下 sell_heavy + OI < -5% = 逼仓前兆（非做空信号），触发陷阱 12

### 修正因子与四维裁决的交互

- 修正因子不改变趋势裁决方向，但**降低置信度一级**（高→中，中→低）
- 薄流动性下所有"高置信"裁决自动降级为"中置信"
- 仓位上限锁定为 1 手（无论置信度多高）
- 触发陷阱 12-14 任一条件时，修正因子升级为否决项

### 实战验证

**2026-08-07**：
- 全天 volume_ratio = 0.0175（极薄流动性），应触发 -20% 修正
- 午后 sell_heavy + OI -6.83% 被误判为做空信号（实际为逼仓前兆）
- RSI 27.4 超卖未提前平仓，3 分钟反弹 28 点导致利润转亏损
- 教训：薄流动性下所有信号需打折处理，RSI 超卖阈值从 30 上调至 35

### 趋势裁决输出模板

```markdown

### 裁决结果
```
