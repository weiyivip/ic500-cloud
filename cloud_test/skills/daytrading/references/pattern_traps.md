# 模式陷阱识别

## 概述

本文件记录从 2026 年 7 月-8 月实战数据中提炼的常见陷阱模式。每种陷阱包含识别条件、应对策略和实战案例。

---

## 陷阱 1：熊市反弹陷阱（Bear Market Rally Trap）

### 识别条件
- 日线 MA 空头排列（`daily_features.future.ma.alignment` = bear）
- 日内大涨（> 2%）
- `oi_trend` = decrease（持仓减少）
- `market_quality` = fake_breakout

### 陷阱逻辑
日线空头排列下的大涨，若持仓量减少，说明是**空头平仓推动的反弹**，而非新多入场。反弹不可持续，随时可能反转下跌。

### 应对策略
- **禁止追多**，即使五层周期短期转多
- 趋势裁决降级：高置信 → 中置信，中置信 → 低置信
- 若持有空单，反弹至阻力位可加仓做空
- 关注反弹高点作为新的做空入场点

### 实战案例
**2026-08-05**：
- 日线 MA：MA5=7396 < MA10=7461 < MA20=7707 < MA60=8171（空头排列）
- 日内涨 +3.03%（7529 → 7757）
- OI 减少 6.8%（`oi_change` = -12398）
- `market_quality` = fake_breakout
- 判定：熊市反弹，禁止追多

## 陷阱 2：假突破陷阱（Fake Breakout Trap）

### 识别条件
- `market_quality` = fake_breakout 持续 2 小时以上
- 价格多次测试同一阻力/支撑位但无法站稳
- 突破时成交量未放大或持仓量未增加

### 陷阱逻辑
fake_breakout 标签持续意味着市场缺乏真实突破动力，突破后大概率回落。追突破的投资者会被套在高位/低位。

### 应对策略
- **禁止追突破**，无论方向
- 突破后等回踩确认再入场（方案 H1）
- 或在突破失败后反向操作（方案 H2）
- 关注突破位作为反向操作的入场点

### 实战案例
**2026-07-31**：
- 7500 点三次突破全部失败
- fake_breakout 持续全天
- 追突破的做多方被套
- 正确操作：7500 点突破失败后做空

## 陷阱 3：卖盘环境反弹陷阱（Sell-Heavy Bounce Trap）

### 识别条件
- `order_imbalance` = sell_heavy
- `buy_sell_ratio` < 0.50
- 价格出现反弹（20-30 点）

### 陷阱逻辑
卖盘主导环境下，反弹是空头平仓或多头自救，幅度有限（通常 20-30 点）。反弹结束后价格大概率继续下跌。将反弹视为"礼物"，果断减仓。

### 应对策略
- 反弹超 20 点 → **立即减仓 50%，命令式语气，不商量**
- 反弹超 30 点 → 减仓 75% 或全部平仓
- 禁止在反弹中加仓做多
- 措辞必须用"立即减仓"而非"建议减仓"

### 实战案例
**2026-07-31**：
- sell_heavy 环境，反弹 24 点
- 未及时减仓，反弹全部吐回
- 教训：反弹 24 点在 sell_heavy 下是"礼物"，必须立即减仓

## 陷阱 4：方向反复震荡陷阱（Direction Flip-Flop Trap）

### 识别条件
- 短时间内（< 1 小时）方向判断多次反转
- `buy_sell_ratio` 在 0.4-0.6 之间快速波动
- 5min MACD 频繁金叉死叉

### 陷阱逻辑
方向反复是市场缺乏明确趋势的表现，通常发生在震荡市或趋势转折期。频繁转向会导致连续止损，侵蚀本金。

### 应对策略
- **方向一致性铁律**：方向确定后不因短期数据波动反转
- `buy_sell_ratio` 波动 ±0.1 以内不视为方向改变
- 如需转向，必须走完整四维裁决流程
- 连续两次止损 → 当日停手

### 实战案例
**2026-07-31**：
- 13:07 做空 → 转头做多 → 再做空 → 再做多
- 方向反复导致混乱和亏损
- 教训：方向确定后不因 buy_sell_ratio 短期波动而反复转向

## 陷阱 5：极端超卖误判陷阱（Extreme Oversold Misjudgment）

### 识别条件
- RSI < 20（极端超卖）
- 日线大背景空头排列
- 盘后预判"空头延续"为主基调

### 陷阱逻辑
极端超卖（RSI < 20）时反弹概率 > 80%，即使大趋势偏空，短期也可能出现强力反弹（幅度可达 200+ 点）。将"空头延续"作为主基调会低估反弹动能。

### 应对策略
- RSI < 20 → 必须在场景概率中给"多修复" >= 40%
- 极端超卖后的反弹可持续到次日
- 盘后预判时，极端超卖日的次日基调应给"震荡偏多"或"超卖反弹"
- 做空方案应暂停，等待反弹结束后再考虑

### 实战案例
**2026-07-30**：
- RSI = 13.4（极端超卖）
- 全天暴跌 212 点（-2.84%）
- 盘后预判"空头延续"
- 次日（7/31）实际反弹 366 点
- 教训：RSI < 20 时反弹概率 > 80%，不可低估

## 陷阱 6：持仓背离陷阱（OI Divergence Trap）

### 识别条件
- 价格上涨 + `oi_trend` = decrease（持仓减少）
- 或价格下跌 + `oi_trend` = increase（持仓增加）

### 陷阱逻辑
- **价格上涨 + OI 减少** = 空头平仓推动，非新多入场 → 假反弹
- **价格下跌 + OI 增加** = 空头主动建仓 → 真下跌
- **价格上涨 + OI 增加** = 多头主动进攻 → 真突破
- **价格下跌 + OI 减少** = 多头止损 → 假下跌（可能反弹）

### 应对策略

| 价格方向 | OI 方向 | 判定 | 操作 |
|----------|---------|------|------|
| 涨 | 增 | 多头进攻 | 可顺势做多 |
| 涨 | 减 | 空头平仓 | 禁止追多，标记假反弹 |
| 跌 | 增 | 空头攻击 | 可顺势做空 |
| 跌 | 减 | 多头止损 | 禁止追空，等反弹 |

### 实战案例
**2026-07-30**：
- OI -10% + 价格暴涨 = 空头平仓
- 判定为假反弹，非新多入场
- 正确识别：OI 减少 + 价格涨 = 反弹不可持续

## 陷阱 7：缺口陷阱（Gap Trap）

### 识别条件
- 开盘高开 > 1%（相对于前日收盘）
- 或开盘低开 > 1%
- A50 夜盘涨幅 > 0.5% 但开盘后走低

### 陷阱逻辑
大幅高开（> 1%）可能是缺口陷阱，开盘后价格回落填补缺口。追高开的投资者会被套。

### 应对策略
- 高开 > 1% → 等 15 分钟确认方向再操作
- 高开后回落至前日收盘价附近 → 缺口填补，可考虑做多
- 高开后继续上涨 + 放量 + OI 增 → 真突破，可追多
- 高开后回落 + 缩量 + OI 减 → 缺口陷阱，观望或做空

### 实战案例
**2026-07-30**：
- 高开低走，缺口陷阱
- 追高的做多方被套
- 教训：高开 > 1% 可能是缺口陷阱

---

## 陷阱 8：薄流动性陷阱（Thin Liquidity Trap）

### 识别条件
- `spread.liquidity_warning` = true
- `spread.volume_ratio` < 0.3
- 持有合约成交量远低于主力合约

### 陷阱逻辑
持有合约（如 IC2609）流动性不足时，买卖价差大，滑点风险高。止损可能无法在指定价格成交，实际亏损大于预期。

### 应对策略
- `liquidity_warning` = true → 减小仓位至 0.5 倍
- `volume_ratio` < 0.1 → 考虑切换合约或观望
- 止损设置预留额外 5-10 点滑点缓冲
- 震荡概率 +20pp（薄流动性日更可能震荡）

### 实战案例
**2026-08-05**：
- `spread.volume_ratio` = 0.0204（极低）
- `liquidity_warning` = true
- IC2609 成交量仅 84350 手（vs 主力 412 万手）
- 判定：薄流动性日，减小仓位，预留滑点缓冲

## 陷阱 9：假金叉陷阱（Fake Golden Cross Trap）

### 识别条件
- 主 MACD `status` = `cross_up`（金叉）
- 主 MACD `hist` < 1.0（金叉力度极弱）
- 5min MACD `status` 仍为 `bear`（短期周期未确认）
- RSI14 < 50（整体偏弱）

### 陷阱逻辑
主 MACD 金叉但力度极弱（hist < 1.0），且短期周期（5min）未同步确认，属于假金叉。价格短暂企稳后会重新死叉下跌，追多者被套在反弹高点。在 sell_heavy 环境下尤其危险——空头平仓制造的微弱金叉信号不具持续性。

### 应对策略
- **禁止追多**，将假金叉视为噪音
- 若持有空单，可继续持有，不必因金叉恐慌平仓
- 可将假金叉视为**空头加仓机会**（金叉后价格回升至阻力位可加空）
- 验证标准：需 5min MACD 同步金叉 + hist > 1.0 + RSI > 50 方可确认真金叉

### 实战案例
**2026-08-06**：
- 11:35 第一次假金叉：主 MACD hist = +1.02（< 1.0），5min MACD 仍 bear，RSI14 = 50.1
- 13:32 第二次假金叉：主 MACD hist = +0.21（极弱），5min MACD 仍 bear
- 两次假金叉后价格均重新下跌，确认空头趋势
- 教训：主 MACD 金叉 hist < 1.0 + 5min MACD 不同步 = 假金叉，不可作为做多依据

## 陷阱 10：假跌破确认陷阱（False Breakdown Confirmation Trap）

### 识别条件
- 价格跌破关键支撑位（< 5 点穿透）
- 跌破后 4 分钟内回抽至支撑位上方
- 跌破时 OI 持续减少（非空头主动打压）
- 成交量未在跌破瞬间放大

### 陷阱逻辑
浅幅跌破（< 5 点）+ 快速回抽 = 支撑有效而非破位。这是空头陷阱，诱使追空者在支撑位下方开空，随后价格反弹止损。OI 减少说明跌破是多头止损推动而非空头攻击，支撑位实际有效。

### 应对策略
- **禁止追空**浅幅跌破（< 5 点穿透）
- 等待跌破后 5 分钟确认：若价格未回抽且 OI 增加 → 真破位，可追空
- 若 4 分钟内回抽至支撑上方 → 假跌破，支撑有效，可考虑在支撑位附近做多
- 结合 buy_sell_ratio：跌破时 ratio 未跌破 0.35 → 卖盘不足以维持破位

### 实战案例
**2026-08-06**：
- 7681 支撑位（前日收盘 MA20）：价格浅幅跌破至 7676（穿透 5 点）
- 4 分钟内回抽至 7681 上方，确认支撑有效
- OI 持续减少（-9.27%），说明跌破是多头止损而非空头攻击
- 随后从 7681 反弹至 7730（+49 点），追空者被套
- 教训：浅幅跌破 + 快速回抽 + OI 减少 = 假跌破，支撑有效

## 陷阱 11：OI 阈值反弹陷阱（OI Threshold Rebound Trap）

### 识别条件
- `oi_change_pct` 从极端值（< -9%）开始收窄
- OI 收窄至 -7.5% 附近时触发反弹
- 反弹幅度通常 25-35 点
- 反弹伴随 `order_imbalance` 从 sell_heavy 转向 buy_heavy

### 陷阱逻辑
OI 极端减少（< -9%）说明空头回补高峰，当 OI 收窄至 -7.5% 临界值时，空头回补接近尾声，剩余空头获利了结推动反弹。此反弹有资金面支撑（真实买盘），但幅度有限（25-35 点），属于技术性修复而非趋势反转。持仓空单在此位置容易被反弹打止损。

### 应对策略
- OI 收窄至 -7.5% → **空单立即减仓 50%**，命令式语气
- OI 收窄至 -6% → 空单全部平仓
- 反弹目标预估 25-35 点，到达后不追多
- 反弹结束后若 sell_heavy 回归 → 可重新做空
- 关键：OI -7.5% 是反弹触发临界值，反弹概率 > 70%

### 实战案例
**2026-08-06**：
- 上午 OI 极端减少至 -9.27%（空头回补高峰）
- 下午 OI 逐步收窄，13:20 左右收窄至 -7.45%
- 触发反弹：价格从 7683 反弹至 7711（+28 点）
- buy_sell_ratio 从 0.35 回升至 0.55，order_imbalance 转向 buy_heavy
- 持仓空单（7717 入场）在反弹中浮盈快速缩水，果断在 7687 平仓锁定 +30 点
- 教训：OI -7.5% 是反弹临界值，持仓空单必须提前减仓保护利润

## 陷阱 12：薄流动性逼仓陷阱（Thin Liquidity Squeeze Trap）

### 识别条件
- `spread.volume_ratio` < 0.03（极薄流动性）
- `oi_change_pct` < -5% 且持续收窄（空头回补中）
- `buy_sell_ratio` < 0.35（极端 sell_heavy）+ 价格不跌反涨
- `market_quality` = fake_breakout 持续

### 陷阱逻辑
薄流动性合约中，sell_heavy + OI decrease 不是做空信号，而是空头被迫平仓的逼仓前兆。少量买盘即可推动价格暴涨，sell_heavy 越强说明空头平仓越 desperate，价格反而越涨。这与常规"sell_heavy = 看空"的判断完全相反。

### 应对策略
- volume_ratio < 0.03 + OI < -5% + sell_heavy → **禁止做空**
- 已持空单 → 反弹至入场价立即平仓，不等待技术信号
- 等 OI 进入 -5% 以内 + 逼仓结束信号（buy_sell_ratio 回归 0.45-0.65）才可考虑做空
- 薄流动性逼仓下，止损宽度需增加 50%（例如：从 20 点 → 30 点）

### 实战案例
**2026-08-07**：
- IC2609 volume_ratio = 0.0175（极薄流动性）
- 午后 OI -6.83% + buy_sell_ratio = 0.333（极端 sell_heavy）
- 价格不跌反涨，从 7800 区域暴力拉升至 7839.4（+39 点）
- 持仓空单（7808 入场）被逼仓止损，亏损 -31 点
- 教训：薄流动性 + OI < -5% + sell_heavy = 逼仓前兆，禁止做空

---

## 陷阱 13：RSI 超卖暴力反弹陷阱（RSI Oversold Violent Rebound Trap）

### 识别条件
- RSI14 < 30（超卖区）
- 薄流动性环境（`spread.volume_ratio` < 0.03）
- 5min MACD hist < -2.0（短期极空但即将反弹）

### 陷阱逻辑
薄流动性下 RSI 超卖反弹极其暴力，3 分钟可反弹 25-30 点。常规"RSI < 20 才平仓"的规则在薄流动性下不够保守。RSI 从 27 反弹至 55（+28 点），空单利润可瞬间变为亏损。薄流动性放大了反弹幅度，因为少量买盘即可推动价格大幅上涨。

### 应对策略
- 薄流动性下（volume_ratio < 0.03）RSI < 30 → **立即平仓，不等 20**
- RSI < 30 + buy_sell_ratio 从 < 0.35 飙升至 > 0.50 → **强制平仓**
- 不要在 RSI 超卖区持有空单过午休（薄流动性午后再 squeeze 风险极高）
- 超卖反弹目标预估：25-30 点（薄流动性下比正常流动性多 5-10 点）

### 实战案例
**2026-08-07**：
- 14:04 RSI14 = 27.4（超卖），volume_ratio = 0.0175（极薄流动性）
- 3 分钟内 RSI 暴涨 27.5 点（27.4 → 54.9），价格从 7842 反弹至 7870（+28 点）
- 持仓空单（7858 入场）浮盈 +16.8 点瞬间变为浮亏 -12 点
- 教训：薄流动性下 RSI < 30 必须立即平仓，不等 RSI < 20

---

## 陷阱 14：零量假 MACD 信号陷阱（Zero-Volume False MACD Signal Trap）

### 识别条件
- 5min 成交量 < 5% 均量（接近零量）
- 主 MACD 出现金叉或死叉
- 5min MACD 方向与主 MACD 不一致

### 陷阱逻辑
5min 成交量极低时（< 5%），MACD 基于极少数据计算，金叉/死叉信号完全不可靠。零量期间的 MACD 交叉在 3-5 分钟后大概率被推翻。将零量 MACD 信号作为交易依据会导致频繁的虚假开仓和止损。

### 应对策略
- 5min 成交量 < 5% → **忽略所有 MACD 交叉信号**
- 等成交量恢复至 30% 以上再评估 MACD
- 零量期间的 MACD status 变化标记为"不可信"
- 若已在零量前持仓，以持仓管理规则为准，不受零量 MACD 信号影响

### 实战案例
**2026-08-07**：
- 13:20 5min 成交量极低（< 5%），主 MACD 出现死叉信号
- 3 分钟后价格不跌反涨，死叉信号被推翻
- 13:40 再次出现零量死叉，5 分钟后被推翻
- 教训：零量期间 MACD 交叉信号不可信，需等放量确认
