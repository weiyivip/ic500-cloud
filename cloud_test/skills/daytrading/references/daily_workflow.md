# 日内工作流

## 概述

本文件定义完整的日内工作流程，包括盘前准备、四段盯盘 checklist、盘后复盘模板和次日计划模板。

---

## 一、盘前准备（09:00-09:30）

### 数据准备
1. 下载最新 `live_summary.json`
2. 检查 `timestamp` 确认数据时效
3. 检查 `holding_contract.symbol` 确认合约代码
4. 检查 `expiry.days_to_expiry` 确认到期风险

### 外盘参考
1. 读取 `intl_market_quotes` 各外盘数据
2. A50 涨跌幅 → 开盘方向预判
3. 港股恒指 → 外资态度
4. 罗素2000 → 小盘股风险偏好（与 IC 相关性高）

### 开盘预判
```
A50 > 0.3% + 港股涨 + 罗素涨 → 偏多开盘
A50 < -0.3% + 港股跌 + 罗素跌 → 偏空开盘
其他 → 震荡开盘
```

### 昨日回顾
1. 读取 `database_data.daily_features` 了解昨日日线状态
2. 读取 `database_data.recent_daily` 了解近 5 日走势
3. 确认日线趋势方向（多头/空头/混合排列）

---

## 二、四段盯盘 Checklist

### 第一段：早盘定基调（09:30-10:30）

**目标**：确定当日基调，寻找首笔交易机会

- [ ] 读取实时 `multi_period_features`，确认五层周期状态
- [ ] 读取 `tick_analysis`，确认 market_quality 和买卖力量
- [ ] 执行四维趋势裁决（见 trend_verdict.md）
- [ ] 快速核对 8 种陷阱（见 pattern_traps.md）
- [ ] 确定市场状态分类（6 种之一）
- [ ] 匹配执行方案（D/E/F/G/C/H 之一）
- [ ] 若有方案：生成完整执行方案（入场/止损/止盈/仓位/时间窗口）
- [ ] 若无方案：明确输出"观望 + 原因"

**首笔交易窗口**：09:30-10:00 是方向最明确的时段，若信号充分应果断入场。

---

### 第二段：午前修复甄别（10:30-11:35）

**目标**：甄别修复行情，管理持仓

- [ ] 若有持仓：执行持仓管理（止损移动 / 减仓 / 目标跟踪）
- [ ] 若无持仓：观察上午走势是否符合预判
- [ ] 识别修复行情：上涨缩量 + 下跌放量 → 趋势衰竭
- [ ] 识别假突破：fake_breakout 持续 → 调整方案
- [ ] 11:30 前决定：午休前是否需要减仓/平仓

---

### 第三段：午后趋势确认（13:00-14:30）

**目标**：确认趋势方向，管理持仓

- [ ] 13:00 重新读取数据，对比上午变化
- [ ] 午休复盘：上午行情定性 + 下午基调预判
- [ ] 若有持仓：继续持仓管理
- [ ] 若无持仓且信号明确：可开新仓（13:00-14:00 窗口）
- [ ] 14:00 后：**禁止开新仓**，仅管理现有持仓
- [ ] 14:20：全部持仓开始退出
- [ ] 14:30：**绝对退出线**，全部平仓

---

### 第四段：尾盘终极风控（14:30-15:00）

**目标**：退出所有持仓，硬锁

- [ ] 14:30-14:40：仅允许顺势强信号（须满足 >= 4 项验证）
- [ ] 14:40-15:00：**彻底硬锁**
  - 【当前决策】强行锁定为【观望】
  - 绝对禁止任何新开仓建议
  - 仅允许对现有持仓进行平仓处理
- [ ] 14:55：确认所有持仓已平仓
- [ ] 15:00：收盘，进入盘后复盘
