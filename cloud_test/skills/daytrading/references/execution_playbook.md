# 六种市场状态执行方案手册

## 概述

根据趋势裁决的市场状态分类，匹配对应的执行方案。每种方案包含完整的入场、止损、止盈、仓位和时间窗口。

---

## 一、六种市场状态与方案匹配

| 市场状态 | 方案类型 | 方向 | 盈亏比底线 | 适用时段 |
|----------|----------|------|-----------|----------|
| 趋势上涨 | D-顺势做多 | 多 | >= 2.50 | 09:30-14:00 |
| 趋势下跌 | E-顺势做空 | 空 | >= 2.50 | 09:30-14:00 |
| 震荡 | F-区间两端 | 多/空 | >= 1.50 | 全天 |
| 超买回调 | G-回调做多 | 多 | >= 2.00 | 等回调后 |
| 超卖反弹 | C-超卖反弹 | 多 | >= 2.00 | 全天 |
| 陷阱行情 | H-回踩/观望 | 多/空 | >= 1.80 | 全天 |

## 二、方案模板

### 方案 D：趋势顺势做多

**触发条件**：
- 五层 4 层 MA bull + 3 层 MACD bull
- `buy_sell_ratio` > 0.60
- `order_imbalance` = buy_heavy
- `oi_trend` = increase（持仓增加）
- 日线大背景偏多或中性

**方案**：
```
方向：多
入场：当前价或回踩 MA5 ± 5 点
止损：MA20 下方 25-30 点（固定止损【因 ATR 口径异常】）
目标1：+50 点（减仓 50%）
目标2：+80-100 点（清仓）
盈亏比：80/30 = 2.67
仓位：高置信 2 手 / 中置信 1 手
时间窗口：09:30-14:00
失效条件：价格跌破 MA20 或 14:00 后未达目标1
```

---

### 方案 E：趋势顺势做空

**触发条件**：
- 五层 4 层 MA bear + 3 层 MACD bear
- `buy_sell_ratio` < 0.45
- `order_imbalance` = sell_heavy
- `oi_trend` = increase（持仓增加，空头主动建仓）
- 日线大背景偏空

**方案**：
```
方向：空
入场：当前价或反弹至 MA5 ± 5 点
止损：MA20 上方 25-30 点（固定止损）
目标1：-50 点（减仓 50%）
目标2：-80-100 点（清仓）
盈亏比：80/30 = 2.67
仓位：高置信 2 手 / 中置信 1 手
时间窗口：09:30-14:00
失效条件：价格突破 MA20 或 14:00 后未达目标1
```

---

### 方案 F：区间两端操作（震荡日）

**触发条件**：
- `composite_score.market_type` = oscillation
- 五层方向不一致（部分 bull 部分 bear）
- RSI 在 35-65 之间波动
- `market_quality` ≠ fake_breakout

**方案**：
```
方向：多（支撑位）/ 空（阻力位）
入场：支撑位 ± 5 点做多 / 阻力位 ± 5 点做空
止损：支撑/阻力位下方/上方 20-25 点（固定止损）
目标1：区间中线（50 点，减仓 50%）
目标2：区间对侧（80-100 点，清仓）
盈亏比：80/25 = 3.20
仓位：中置信 1 手 / 低置信 0.5 手
时间窗口：全天（14:00 后不开新仓）
失效条件：价格突破区间边界 20 点（区间失效）
```

**区间操作铁律**：
- 只在区间两端操作，中间区域观望
- 突破区间边界 20 点 → 区间失效，停止区间操作
- 每次操作只做一端，不同时挂双向

---

### 方案 G：回调做多（超买回调后）

**触发条件**：
- RSI14 > 70 或多周期 RSI > 75
- 等待价格回调至 MA10 或 MA20 附近
- 回调时缩量 + `buy_sell_ratio` 仍 > 0.55
- 日线大背景非空头排列

**方案**：
```
方向：多
入场：回调至 MA10/MA20 ± 5 点
止损：MA20 下方 20-25 点（固定止损）
目标1：+50 点（减仓 50%）
目标2：+80-100 点（清仓）
盈亏比：80/25 = 3.20
仓位：中置信 1 手
时间窗口：回调确认后 09:30-14:00
失效条件：价格跌破 MA20 或回调时放量 + sell_heavy
```

**注意**：
- 禁止在 RSI > 80 时追多
- 必须等回调确认（价格触及 MA10/MA20 + 5min MACD 仍 bull）
- 若回调时 `order_imbalance` 转 sell_heavy → 放弃方案

---

### 方案 C：超卖反弹做多

**触发条件**：
- RSI14 < 30 或 `multi_period_features.30min.rsi.value` < 25
- 价格触底后 Tick 开始回升
- 30/60/180min MACD 有至少 1 层 bull

**方案**：
```
方向：多
入场：当前价或低点 + 5 点
止损：低点下方 20 点（固定止损）
目标1：+50 点（减仓 50%）
目标2：+80-100 点（清仓）
盈亏比：80/20 = 4.00
仓位：低置信 0.5 手（极端超卖 RSI<20 可 1 手）
时间窗口：全天（14:00 后不开新仓）
失效条件：价格创新低或 30 分钟内无反弹
```

**经验参数**：
- RSI < 20：反弹幅度常超 200 点（参照 7/30 RSI=13.4 → 次日反弹 366 点）
- RSI 25-30：反弹幅度常在 30-50 点（可能不足以达到 50 点目标1，需结合放量或大周期共振确认）
- 反弹可能持续到次日（不限于当日）

---

### 方案 H：陷阱行情应对

**触发条件**：
- `market_quality` = fake_breakout 持续 2 小时以上
- 或 OI 减少 + 价格涨（空头平仓反弹）
- 或 OI 减少 + 价格跌（多头止损下跌）

**方案选择**：

**H1-回踩做多**（fake_breakout + 五层偏多）：
```
方向：多
入场：突破位回踩 ± 5 点（不追突破，等回踩确认）
止损：回踩低点下方 20 点
目标1：+50 点（减仓 50%）
目标2：+80-100 点（清仓）
盈亏比：80/20 = 4.00
```

**H2-假突破做空**（fake_breakout + 五层偏空）：
```
方向：空
入场：阻力位 ± 10 点（冲高回落时）
止损：阻力位上方 30-35 点
目标1：-50 点（减仓 50%）
目标2：-80-100 点（清仓）
盈亏比：80/35 = 2.29
```

**H3-观望**（陷阱信号不明确）：
```
方向：观望
原因：fake_breakout 持续 + OI 背离 + 方向不明确
等待：market_quality 切换为 active_attack 或趋势明确后入场
```

## 三、方案选择决策树

```
Step 1: market_quality = fake_breakout 且持续 > 2 小时？
├─ YES → 方案 H（陷阱行情应对）
└─ NO → Step 2

Step 2: RSI14 < 30 或 30min RSI < 25？
├─ YES → 方案 C（超卖反弹）
└─ NO → Step 3

Step 3: RSI14 > 70 或多周期 RSI > 75？
├─ YES → 方案 G（回调做多，等回调）
└─ NO → Step 4

Step 4: composite_score.market_type = oscillation？
├─ YES → 方案 F（区间两端）
└─ NO → Step 5

Step 5: 五层共振方向？
├─ 强共振多 + OI 增 → 方案 D（顺势做多）
├─ 强共振空 + OI 增 → 方案 E（顺势做空）
├─ 弱共振 / OI 背离 → 观望
└─ 方向冲突 → 观望
```

## 四、持仓管理

### 止损移动阶梯

#### 做多持仓

| 浮盈 | 止损位 | 说明 |
|------|--------|------|
| 0-10 点 | 原止损不动 | 给波动空间 |
| 10-20 点 | 上移至入场价（保本） | 不亏 |
| 20-30 点 | 上移至入场价 + 5 点 | 锁 5 点 |
| 30-50 点 | 上移至目标1 - 10 点 | 锁大部分利润 |
| > 50 点 | 跟随价格，保持 10 点距离 | 移动止盈 |

#### 做空持仓

| 浮盈 | 止损位 | 说明 |
|------|--------|------|
| 0-10 点 | 原止损不动 | 给波动空间 |
| 10-20 点 | 下移至入场价（保本） | 不亏 |
| 20-30 点 | 下移至入场价 - 5 点 | 锁 5 点 |
| 30-50 点 | 下移至目标1 + 10 点 | 锁大部分利润 |
| > 50 点 | 跟随价格，保持 10 点距离 | 移动止盈 |

### 减仓决策树

#### 做多持仓减仓

```
持仓做多，当前浮盈 X 点
  │
  ├─ X >= 目标1？
  │    └─ YES → 减仓 50%，止损上移至目标1 - 10 点
  │
  ├─ order_imbalance 从 buy_heavy 转 sell_heavy？
  │    └─ YES → 立即减仓 50%，不商量
  │
  ├─ buy_sell_ratio 跌破 0.5？
  │    └─ YES → 减仓 50%
  │
  ├─ market_quality 转为 fake_breakout？
  │    └─ YES → 减仓 50%
  │
  ├─ 5min MACD 从 bull 转 bear + 价格跌破 MA5？
  │    └─ YES → 减仓 25%
  │
  ├─ 14:20？
  │    └─ 全部平仓
  │
  └─ 14:30？
       └─ 绝对退出，全部平仓
```

#### 做空持仓减仓

```
持仓做空，当前浮盈 X 点
  │
  ├─ X >= 目标1？
  │    └─ YES → 减仓 50%，止损下移至目标1 + 10 点
  │
  ├─ order_imbalance 从 sell_heavy 转 buy_heavy？
  │    └─ YES → 立即减仓 50%
  │
  ├─ buy_sell_ratio 升破 0.6？
  │    └─ YES → 减仓 50%
  │
  ├─ RSI < 25（超卖反弹启动）？
  │    └─ YES → 立即减仓 50%
  │
  ├─ 5min MACD 从 bear 转 bull + 价格突破 MA5？
  │    └─ YES → 减仓 25%
  │
  ├─ 14:20？
  │    └─ 全部平仓
  │
  └─ 14:30？
       └─ 绝对退出，全部平仓
```

### 反手操作规则

**默认禁止反手**（平仓后立刻反方向开仓）。

允许反手的条件（**全部满足**）：
1. 原方向止损触发，已平仓
2. `market_quality` 发生变化（如 fake_breakout → active_attack）
3. `buy_sell_ratio` 跨越 0.5 分界线
4. 至少 3 个周期 MACD 方向一致
5. 距 14:00 还有 > 1 小时

反手后止损收紧至 20 点以内。

## 五、时间分段执行规则

| 时段 | 可用方案 | 禁用方案 | 最大目标 | 开仓限制 |
|------|----------|----------|----------|----------|
| 09:30-11:30 | C/D/E/F/G/H | 无 | 100 点 | 正常 |
| 11:30-13:00 | 午休复盘 | 所有新开仓 | - | 准备下午方案 |
| 13:00-14:00 | C/F/G/H | D/E（100 点目标不足） | 50 点 | 止损收紧 |
| 14:00-14:30 | 仅管理持仓 | 所有新开仓 | - | 禁止新仓 |
| 14:20 | 全部开始平仓 | - | - | 退出倒计时 |
| 14:30 | 绝对退出 | - | - | 全部平仓 |
| 14:40 | **硬锁** | - | - | **系统强制观望** |

### 剩余时间与目标匹配

| 剩余时间 | 最大现实目标 | 开仓建议 |
|----------|-------------|----------|
| > 2 小时 | 80-100 点 | 可开仓 |
| 1-2 小时 | 50 点 | 可开仓，止损收紧 |
| 30-60 分钟 | 不足 50 点 | 不开新仓，仅管理持仓 |
| < 30 分钟 | 不交易 | 全部平仓 |
