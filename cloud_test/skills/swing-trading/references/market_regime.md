# 市场体制分类系统

## 概述

本系统将市场划分为 6 种体制，每种体制对应不同的操作策略。体制判定是中长线交易的基础，决定了做多还是做空、持仓还是观望。

---

## 一、六种市场体制

### 1. 牛市趋势（Bull Trend）

**识别条件**（满足 >= 4 项）：
- MA5 > MA10 > MA20 > MA60（完整多头排列）
- MACD bull + hist 持续扩大
- RSI > 55
- 成交量 > vol_ma（放量）
- OI 多日增加（新多建仓）
- 布林带 trend = uptrend + position > 50%

**操作策略**：顺势做多，回踩 MA10 加仓
**止损位**：MA20 下方 30-50 点
**目标**：+200-400 点

### 2. 熊市趋势（Bear Trend）

**识别条件**（满足 >= 4 项）：
- MA5 < MA10 < MA20 < MA60（完整空头排列）
- MACD bear + hist 持续扩大（负值加深）
- RSI < 45
- 成交量 > vol_ma（放量）
- OI 多日增加（空头建仓）
- 布林带 trend = downtrend + position < 50%

**操作策略**：顺势做空，反弹至 MA10 加仓
**止损位**：MA20 上方 30-50 点
**目标**：-200-400 点

### 3. 熊市反弹（Bear Rally）

**识别条件**（满足 >= 3 项）：
- MA60 仍在 MA5/MA10/MA20 上方（长期空头未逆转）
- 价格上涨（日线连续收阳或涨幅 > 5%）
- OI 多日减少（空头平仓，非新多入场）
- 成交量 < vol_ma（缩量）
- RSI 从超卖区（<30）反弹至 40-65
- MACD 可能出现金叉但 hist 仍在负值区或刚转正

**操作策略**：
- **禁止追多**：OI 减少 + 缩量 = 反弹不可持续
- 等待反弹衰竭后做空
- 反弹衰竭信号：RSI > 70 后回落 / MACD 死叉 / 放量滞涨 / 触及 MA60 阻力
**止损位**：反弹高点上方 50-80 点
**目标**：-150-300 点（回到反弹起点或前低）

### 4. 牛市回调（Bull Pullback）

**识别条件**（满足 >= 3 项）：
- MA60 仍在 MA5/MA10/MA20 下方（长期多头未逆转）
- 价格下跌（日线连续收阴或跌幅 > 3%）
- OI 多日减少（多头获利平仓）
- 成交量 < vol_ma（缩量回调）
- RSI 从超买区（>70）回落至 45-60
- MACD 可能死叉但 hist 仍在正值区

**操作策略**：
- 等待回调至 MA20 或 MA60 附近做多
- 回调确认信号：缩量企稳 + RSI 企稳 + MACD 重新金叉
**止损位**：MA60 下方 30-50 点
**目标**：+200-400 点（回到前高或创新高）

### 5. 震荡区间（Range）

**识别条件**（满足 >= 3 项）：
- MA5 ≈ MA10 ≈ MA20（均线粘合，间距 < 1%）
- MACD 反复金叉死叉（hist 在 0 附近震荡）
- RSI 在 40-60 之间波动
- 价格在明确区间内来回（区间宽度 < ATR 的 3 倍）
- 成交量稳定（5日均量在 vol_ma 的 0.8-1.2 倍之间）
- 布林带 trend = sideways + strength 收缩

**操作策略**：区间两端操作
- 区间上沿做空，止损上沿上方 30 点
- 区间下沿做多，止损下沿下方 30 点
- 突破区间 50 点 → 区间失效，停止区间操作
**目标**：区间宽度的 60-80%

### 6. 转折期（Transition）

**识别条件**（满足 >= 2 项）：
- MA 排列发生变化（如 MA5 从上方穿越 MA10，或 MA10 穿越 MA20）
- MACD 发生交叉（金叉或死叉）
- OI 方向发生逆转（从增到减或反向）
- RSI 从极值区回归中性（从 >70 降至 50-60，或从 <30 升至 40-50）
- 布林带 trend 发生变化

**操作策略**：
- **等待确认**：转折期信号不稳定，需 3 个以上维度同时变化才可确认
- 确认后按新体制操作
- 未确认前保持观望或维持原有方向的小仓位
**注意**：转折期最长持续 3-5 天，超过则视为新体制已确立

## 二、体制判定优先级

当多个体制条件部分满足时，按以下优先级判定：

```
优先级 1：熊市反弹 / 牛市回调
  ↓ （不满足则检查）
优先级 2：牛市趋势 / 熊市趋势
  ↓ （不满足则检查）
优先级 3：震荡区间
  ↓ （不满足则检查）
优先级 4：转折期
```

**优先级逻辑**：
- 熊市反弹和牛市回调优先级最高，因为误判代价最大（追多熊市反弹 = 重大亏损）
- 趋势型判定需要更严格的条件（>= 4 项）
- 震荡和转折是"兜底"判定

## 三、关键判别规则

### 规则 1：OI 是核心鉴别器

| 价格方向 | OI 方向 | 体制判定 | 含义 |
|----------|---------|----------|------|
| 涨 | 增 | 牛市趋势 | 新多入场，真牛市 |
| 涨 | 减 | 熊市反弹 | 空头平仓，假牛市 |
| 跌 | 增 | 熊市趋势 | 空头入场，真熊市 |
| 跌 | 减 | 牛市回调 | 多头平仓，假熊市 |

### 规则 2：MA60 是分水岭

- MA60 在 MA5/MA10/MA20 **上方** → 长期空头未逆转 → 任何上涨先视为**反弹**
- MA60 在 MA5/MA10/MA20 **下方** → 长期多头未逆转 → 任何下跌先视为**回调**
- MA60 与 MA20 **交叉** → 可能进入**转折期**

### 规则 3：成交量是确认器

- 放量上涨 → 趋势真实
- 缩量上涨 → 趋势可疑（可能是反弹）
- 放量下跌 → 趋势真实
- 缩量下跌 → 趋势可疑（可能是回调）

### 规则 4：RSI 位置辅助判定

| RSI 区间 | 配合涨势 | 配合跌势 |
|----------|----------|----------|
| > 70 | 超买，趋势末期 | 超买反弹后可能继续跌 |
| 55-70 | 强势多头 | 偏强但可能回落 |
| 45-55 | 中性 | 中性 |
| 30-45 | 偏弱反弹 | 弱势空头 |
| < 30 | 超卖反弹 | 超卖，趋势末期 |

## 四、体制转换规则

### 转换条件（需 >= 3 个维度同时变化）

1. **MA 排列变化**：如从空头排列转为多头排列（MA5 穿越 MA10 + MA10 穿越 MA20）
2. **MACD 交叉**：金叉或死叉且 hist 变化方向持续
3. **OI 方向逆转**：从增到减或从减到增，且持续 >= 3 天
4. **RSI 跨越关键位**：从 < 30 升至 > 50，或从 > 70 降至 < 50
5. **布林带 trend 变化**：从 downtrend 变 uptrend 或反向

### 常见转换路径

```
熊市趋势 → 熊市反弹（OI 开始减少 + RSI < 20）
熊市反弹 → 转折期（OI 停止减少 + MA60 被突破）
转折期 → 牛市趋势（MA 多头排列 + OI 增加 + 放量）
牛市趋势 → 牛市回调（OI 开始减少 + RSI > 70）
牛市回调 → 转折期（MA60 被跌破）
转折期 → 熊市趋势（MA 空头排列 + OI 增加 + 放量）
```

### 转换确认期

- 从一种体制转换到另一种，通常有 3-5 天的**转换确认期**
- 确认期内按"转折期"处理（观望或小仓位）
- 确认完成后（>= 3 维度一致），按新体制操作

## 五、实战验证

### 2026-07-30 至 2026-08-11：熊市反弹判定

**初始状态**（7/30）：
- MA5 < MA10 < MA20 < MA60（空头排列）
- RSI = 13.4（极端超卖）
- OI 减少 -10%
- 判定：**熊市趋势 + 极端超卖**

**反弹过程**（7/31-8/11）：
- 价格从低点反弹 +10.8%
- MA5 穿越 MA10，MA5 穿越 MA20（短期转多）
- 但 MA60 仍在上方（7964 vs 8171+）
- OI 持续减少（5日累计 -10.15%）
- 成交量持续低于 vol_ma

**体制判定**：
- 熊市反弹条件满足 5/6 项：MA60 在上方 / 价格涨 >5% / OI 多日减少 / 缩量 / RSI 从超卖反弹 / MACD 金叉但 hist 偏弱
- **判定为熊市反弹**（非牛市趋势）

**关键教训**：
- 价格涨 10% 不等于牛市
- OI 减少的上涨是空头平仓，不是新多入场
- 缩量上涨不可持续
- MA60 未被突破前，所有上涨都是反弹
