# 多日持仓管理系统

## 概述

中长线持仓管理与日内持仓管理有本质区别：持仓周期长（3-10 天）、止损宽（80-150 点）、目标大（150-400 点）。本系统定义分阶段管理、移动止损、加减仓规则和时间退出机制。

---

## 一、分阶段持仓管理

### 阶段 1：方向验证期（第 1-2 天）

**管理重点**：验证方向是否正确

| 情况 | 判定 | 操作 |
|------|------|------|
| 浮盈 0-50 点 | 方向待确认 | 持有，止损不动 |
| 浮盈 50-100 点 | 方向初步确认 | 持有，止损移至保本 |
| 浮亏 0-50 点 | 正常波动 | 持有，止损不动 |
| 浮亏 50-80 点 | 方向可疑 | 收紧止损至 -80 点 |
| 浮亏 > 80 点（止损触发） | 方向错误 | 止损平仓，不补仓 |

**铁律**：第 1-2 天不加仓（方向未确认）

### 阶段 2：趋势确认期（第 3-5 天）

**管理重点**：确认趋势，开始保护利润

| 情况 | 判定 | 操作 |
|------|------|------|
| 浮盈 100-150 点 | 趋势确认 | 止损移至入场 + 30 点 |
| 浮盈 150-200 点 | 趋势较强 | 可加仓 0.5 手 |
| 浮盈 50-100 点 | 趋势偏弱 | 止损移至保本，不加仓 |
| 浮盈 0-50 点 | 趋势未发展 | 止损移至 -50 点，观察 1 天 |
| 浮亏 | 趋势错误 | 止损平仓 |

**加仓条件**（全部满足）：
1. 浮盈 > 150 点
2. 趋势持续性评分仍 >= +2（做多）或 <= -2（做空）
3. OI 方向未逆转
4. 成交量未大幅萎缩
5. 距到期日 >= 3 天

### 阶段 3：利润保护期（第 6-8 天）

**管理重点**：锁定利润，防止回吐

| 情况 | 判定 | 操作 |
|------|------|------|
| 浮盈 > 200 点 | 趋势持续 | 止损移至入场 + 100 点 |
| 浮盈 > 300 点 | 趋势强劲 | 达到目标1，减仓 50% |
| 浮盈 100-200 点 | 趋势放缓 | 止损移至入场 + 50 点 |
| 浮盈 < 100 点 | 趋势衰竭 | 减仓 50%，止损移至保本 |

**减仓触发条件**（任一满足）：
1. 达到目标1 → 减仓 50%
2. 趋势衰竭信号 >= 2 个 → 减仓 50%
3. 体制判定发生变化 → 减仓 50%
4. OI 方向逆转 → 减仓 50%

### 阶段 4：退出准备期（第 9-10 天）

**管理重点**：准备退出

| 情况 | 操作 |
|------|------|
| 浮盈 > 300 点 | 第 9 天清仓（利润足够） |
| 浮盈 150-300 点 | 第 10 天收盘前清仓 |
| 浮盈 0-150 点 | 第 10 天收盘前清仓（时间退出） |
| 浮亏 | 第 10 天收盘前平仓（时间退出） |

**延期条件**（全部满足才可延期）：
1. 趋势持续性评分仍 >= +4（做多）或 <= -4（做空）
2. 浮盈 > 200 点
3. 无衰竭信号
4. OI 方向未逆转
5. 最多延期 3 天（总持仓不超过 13 天）

## 二、移动止损阶梯

### 做多持仓

| 浮盈 | 止损位 | 说明 |
|------|--------|------|
| 0-50 点 | 原止损不动 | 给波动空间 |
| 50-100 点 | 移至入场价（保本） | 不亏 |
| 100-200 点 | 移至入场 + 50 点 | 锁 50 点 |
| 200-300 点 | 移至目标1 - 30 点 | 锁大部分利润 |
| > 300 点 | 跟随 MA10，保持 30 点距离 | 移动止盈 |

### 做空持仓

| 浮盈 | 止损位 | 说明 |
|------|--------|------|
| 0-50 点 | 原止损不动 | 给波动空间 |
| 50-100 点 | 移至入场价（保本） | 不亏 |
| 100-200 点 | 移至入场 - 50 点 | 锁 50 点 |
| 200-300 点 | 移至目标1 + 30 点 | 锁大部分利润 |
| > 300 点 | 跟随 MA10，保持 30 点距离 | 移动止盈 |

## 三、加减仓规则

### 加仓规则

**前提条件**（全部满足）：
1. 当前持仓浮盈 > 100 点
2. 趋势持续性评分未下降
3. 距到期日 >= 3 天
4. 仓位未达上限（2 手 / 薄流动性 1 手）

**加仓操作**：
- 每次加仓 0.5 手
- 加仓后总止损 = 原止损 和 加仓止损 的加权平均
- 加仓点：回踩 MA10 ± 10 点（做多）/ 反弹至 MA10 ± 10 点（做空）

**加仓后仓位管理**：
- 加仓部分独立管理止损
- 加仓后总仓位不超过上限
- 加仓后若浮盈回撤至 0 → 全部平仓

### 减仓规则

**触发条件**（任一满足）：
1. 达到目标1 → 减仓 50%
2. 趋势衰竭信号 >= 2 个 → 减仓 50%
3. 体制判定发生变化 → 减仓 50%
4. OI 方向逆转 → 减仓 50%
5. 浮盈回撤 > 50%（从最高点） → 减仓 50%

**减仓后管理**：
- 剩余仓位止损移至保本 + 50 点
- 剩余仓位继续持有至目标2 或到期日
- 减仓后不加仓

## 四、时间退出机制

### 到期退出

| 持仓天数 | 操作 |
|----------|------|
| 第 8 天 | 评估是否满足延期条件 |
| 第 9 天 | 不满足延期 → 准备退出 |
| 第 10 天 | 收盘前全部平仓（强制） |

### 趋势反转退出

**反转确认**（>= 3 项满足）：
1. MA 排列逆转
2. MACD 交叉且持续
3. OI 方向逆转
4. RSI 跨越关键位
5. 布林带 trend 逆转

**反转退出操作**：
- 立即全部平仓，不等目标
- 不反手开仓（需重新走完整流程）

### 异常退出

| 异常情况 | 操作 |
|----------|------|
| 跳空 > 100 点（不利方向） | 开盘立即平仓 |
| 重大消息/事件 | 评估后决定，默认减仓 50% |
| 流动性突然恶化 | 立即平仓 |
| 持仓合约临近交割 | 提前 3 天移仓或平仓 |

## 五、薄流动性修正

当 `spread.volume_ratio` < 0.03 时，持仓管理需修正：

| 修正项 | 正常 | 薄流动性 |
|--------|------|----------|
| 仓位上限 | 2 手 | 1 手 |
| 止损宽度 | 标准 | +50% |
| 加仓条件 | 浮盈 > 100 点 | 浮盈 > 150 点 + 不加仓 |
| 移动止损间距 | 30 点 | 50 点 |
| 到期退出 | 第 10 天 | 第 7 天（提前退出） |

**薄流动性特殊规则**：
1. 薄流动性下不加仓（波动大，加仓风险高）
2. 止损宽度 = 标准宽度 * 1.5（防止滑点）
3. 到期退出提前至第 7 天（流动性可能进一步恶化）
4. 跳空风险加倍（薄流动性下隔夜跳空更大）

## 七、实战验证

### 2026-08-11：熊市反弹末端做空方案

**体制判定**：熊市反弹（满足 5/6 项条件）
**趋势持续性评分**：0（弱）→ 方向中性，但资金面偏空

**方案**：
```
方向：空（反弹末端做空）
市场体制：熊市反弹
趋势持续性：0（弱）→ 持仓 3-5 天，仓位 0.5 手
入场价：7960-8000（前高 + 整数关口共振区）
止损价：8050（整数关口上方 50 点，止损 50-90 点）
目标1：7800（-160-200 点，减仓 50%）
目标2：7700（-260-300 点，清仓）
盈亏比：200/90 = 2.22（满足 >= 2.0）
仓位：0.5 手（持续性弱 + 薄流动性约束）
持仓周期：3-5 天
时间退出：第 5 天收盘前平仓
逻辑链：
  1. [技术] MA 排列：MA60 在上方，长期空头未逆转
  2. [技术] MACD：金叉但 hist 偏弱，动能不足
  3. [技术] RSI：55-65，偏多但接近超买区
  4. [资金] OI 多日趋势：5日累计 -10.15%，空头平仓非新多
  5. [资金] 成交量：持续缩量，反弹不可持续
  6. [风控] 止损位 8050：整数关口上方 + 前高上方
```

**持仓管理计划**：
- 第 1-2 天：若价格在 7960-8000 入场，止损 8050 不动
- 第 3 天：若浮盈 > 50 点，止损移至 8000（保本）
- 第 4 天：若浮盈 > 100 点，止损移至 7950（锁 50 点）
- 第 5 天：收盘前全部平仓（时间退出）
