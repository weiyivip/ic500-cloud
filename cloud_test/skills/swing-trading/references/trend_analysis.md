# 趋势持续性评估框架

## 概述

判定趋势是否能持续，是中长线交易的核心问题。本框架通过六个维度评估趋势持续性，并给出衰竭信号和反转判定规则。

---

## 一、六维度趋势评分

### 维度 1：MA 趋势强度（权重 25%）

| 条件 | 评分 | 含义 |
|------|------|------|
| MA5 > MA10 > MA20 > MA60 + 间距扩大 | +2 | 多头趋势增强 |
| MA5 > MA10 > MA20 > MA60 + 间距稳定 | +1 | 多头趋势稳定 |
| MA5 > MA10 > MA20，MA60 在上方 | 0 | 短期多头但长期压力 |
| MA 粘合（间距 < 1%） | 0 | 无趋势 |
| MA5 < MA10 < MA20，MA60 在下方 | 0 | 短期空头但长期支撑 |
| MA5 < MA10 < MA20 < MA60 + 间距稳定 | -1 | 空头趋势稳定 |
| MA5 < MA10 < MA20 < MA60 + 间距扩大 | -2 | 空头趋势增强 |

**间距计算**：`(MA5 - MA10) / MA10 * 100%`，> 0.5% 为扩大，0.1-0.5% 为稳定

### 维度 2：MACD 动能（权重 20%）

| 条件 | 评分 | 含义 |
|------|------|------|
| bull + hist 正值且持续扩大 | +2 | 多头动能增强 |
| bull + hist 正值但开始缩小 | +1 | 多头动能减弱 |
| bull + hist 接近 0 | 0 | 多头动能衰竭 |
| bear + hist 接近 0 | 0 | 空头动能衰竭 |
| bear + hist 负值但开始缩小 | -1 | 空头动能减弱 |
| bear + hist 负值且持续扩大 | -2 | 空头动能增强 |

### 维度 3：RSI 位置（权重 15%）

| RSI 区间 | 评分 | 含义 |
|----------|------|------|
| > 80 | +1（趋势末期） | 极端超买，回调 imminent |
| 65-80 | +2 | 强势多头，趋势持续 |
| 55-65 | +1 | 偏多，趋势较稳 |
| 45-55 | 0 | 中性，无方向 |
| 35-45 | -1 | 偏空，趋势较稳 |
| 20-35 | -2 | 强势空头，趋势持续 |
| < 20 | -1（趋势末期） | 极端超卖，反弹 imminent |

### 维度 4：布林带位置（权重 15%）

| 位置 | 评分 | 含义 |
|------|------|------|
| > 80% + uptrend | +2 | 强势上攻 |
| 60-80% + uptrend | +1 | 偏多上行 |
| 40-60% + sideways | 0 | 中性震荡 |
| 20-40% + downtrend | -1 | 偏空下行 |
| < 20% + downtrend | -2 | 强势下跌 |
| > 90% | 超买警告 | 即将回调 |
| < 10% | 超卖警告 | 即将反弹 |

### 维度 5：OI 多日趋势（权重 15%）

| 5 日 OI 变化 | 评分 | 含义 |
|-------------|------|------|
| > +3% | +2 | 持续建仓，趋势真实 |
| 0 ~ +3% | +1 | 温和建仓 |
| -3% ~ 0 | -1 | 温和平仓，趋势可疑 |
| < -3% | -2 | 大规模平仓，趋势虚假 |

**OI 多日趋势判断方法**：
- 读取 `database_data.recent_daily` 获取近 5 日 OI 数据
- 计算累计变化率：`(当前 OI - 5日前 OI) / 5日前 OI * 100%`
- 同时观察 OI 变化方向是否一致（持续减少 vs 时增时减）

### 维度 6：成交量趋势（权重 10%）

| 5 日均量 vs vol_ma | 评分 | 含义 |
|---------------------|------|------|
| > 1.2 倍 | +1 | 放量确认趋势 |
| 1.0-1.2 倍 | 0 | 正常 |
| 0.8-1.0 倍 | -0.5 | 轻度缩量 |
| < 0.8 倍 | -1 | 缩量，趋势可疑 |

## 二、趋势持续性总评

| 总分 | 趋势持续性 | 持仓建议 | 仓位 |
|------|-----------|----------|------|
| >= +6 | 极强 | 持仓 10 天 | 2 手 |
| +4 ~ +5 | 强 | 持仓 7-10 天 | 1.5 手 |
| +2 ~ +3 | 中 | 持仓 5-7 天 | 1 手 |
| 0 ~ +1 | 弱 | 持仓 3-5 天 | 0.5 手 |
| -1 ~ 0 | 弱（反向） | 持仓 3-5 天 | 0.5 手 |
| -3 ~ -2 | 中（反向） | 持仓 5-7 天 | 1 手 |
| -5 ~ -4 | 强（反向） | 持仓 7-10 天 | 1.5 手 |
| <= -6 | 极强（反向） | 持仓 10 天 | 2 手 |

**方向判定**：总分 > 0 → 做多方向；总分 < 0 → 做空方向；总分 = 0 → 观望

## 三、趋势衰竭信号

当趋势持续一段时间后，以下信号提示趋势可能即将衰竭：

### 做多趋势衰竭信号

| 信号 | 条件 | 含义 |
|------|------|------|
| RSI 超买 | RSI > 80 或从 > 70 快速回落 | 上涨动能衰竭 |
| MACD 顶背离 | 价格创新高但 MACD hist 未创新高 | 上涨动能减弱 |
| 放量滞涨 | 成交量放大但价格涨幅缩小 | 主力出货 |
| OI 由增转减 | OI 从增加转为减少 | 多头获利平仓 |
| 触及布林上轨 | position > 90% + 开始回落 | 技术性回调 |
| MA5 下穿 MA10 | MA5 从上方穿越 MA10 | 短期趋势转弱 |

### 做空趋势衰竭信号

| 信号 | 条件 | 含义 |
|------|------|------|
| RSI 超卖 | RSI < 20 或从 < 30 快速反弹 | 下跌动能衰竭 |
| MACD 底背离 | 价格创新低但 MACD hist 未创新低 | 下跌动能减弱 |
| 缩量止跌 | 成交量缩小且价格跌幅缩小 | 卖压减弱 |
| OI 由增转减 | OI 从增加转为减少 | 空头获利平仓 |
| 触及布林下轨 | position < 10% + 开始反弹 | 技术性反弹 |
| MA5 上穿 MA10 | MA5 从下方穿越 MA10 | 短期趋势转强 |

**衰竭信号强度**：单个信号 = 警告（收紧止损）；>= 2 个信号 = 减仓 50%；>= 3 个信号 = 清仓

## 四、趋势反转判定

### 反转触发条件（满足 >= 3 项）

1. **MA 排列完全逆转**：从多头排列转为空头排列（或反向）
2. **MACD 交叉且持续**：MACD 发生金叉/死叉且 hist 方向持续 >= 3 天
3. **OI 方向逆转**：OI 从增变减（或反向）且持续 >= 3 天
4. **RSI 跨越关键位**：从 > 60 降至 < 40（或反向）
5. **布林带 trend 逆转**：从 uptrend 变 downtrend（或反向）
6. **价格突破关键位**：突破 MA60 或前高/前低

### 反转处理流程

1. 确认反转条件（>= 3 项满足）
2. 显式说明"原趋势判断需要修正的原因"
3. 重新走完整五步法流程
4. 生成新方向交易方案
5. 止损收紧至 50 点以内（反转初期波动大）

### 反转禁止场景

- 体制判定为"熊市反弹"时，反弹过程中的短期回调不视为反转
- 单一维度变化不构成反转（必须 >= 3 维度确认）
- 薄流动性环境下（volume_ratio < 0.03）的反转信号需额外 1 天确认

## 五、薄流动性修正

当 `spread.volume_ratio` < 0.03 时，趋势持续性评估需修正：

| 修正项 | 正常 | 薄流动性 |
|--------|------|----------|
| 信号可信度 | 100% | -20%（降一级） |
| RSI 超买阈值 | 70 | 65 |
| RSI 超卖阈值 | 30 | 35 |
| 仓位上限 | 2 手 | 1 手 |
| 止损宽度 | 标准 | +50% |
| MACD 交叉确认 | 1 根 K 线 | 2 根 K 线 |

**修正方法**：
1. 先按正常流程计算六维度评分
2. 薄流动性下总评分降一级（如 +3 → +2）
3. 仓位上限锁定为 1 手
4. 止损宽度 = 标准宽度 * 1.5

## 六、实战验证

### 2026-08-11：熊市反弹持续性评估

**六维度评分**：

| 维度 | 数据 | 评分 |
|------|------|------|
| MA 趋势强度 | MA5 > MA10 > MA20，MA60 在上方 | 0 |
| MACD 动能 | bull + hist 正值但缩小 | +1 |
| RSI 位置 | 55-65 | +1 |
| 布林带位置 | 60-80% + uptrend | +1 |
| OI 多日趋势 | 5日累计 -10.15% | -2 |
| 成交量趋势 | 5日均量 < vol_ma * 0.8 | -1 |

**总分**：0 + 1 + 1 + 1 - 2 - 1 = **0**

**持续性判定**：弱 → 持仓 3-5 天，仓位 0.5 手

**方向判定**：总分 = 0 → 观望（OI 和成交量的负分抵消了技术面的正分）

**解读**：
- 技术面偏多（MA 短期多头 + MACD bull + RSI 偏强 + 布林带偏多）= +3
- 资金面偏空（OI 大幅减少 + 缩量）= -3
- 技术面与资金面背离 → 趋势不可信 → 观望

**操作建议**：等待 OI 停止减少 + 成交量放量后再做多；或在反弹衰竭信号出现后做空
