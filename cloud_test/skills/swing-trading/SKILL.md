# IC500 十天中长线趋势判断与交易方案

## 定位

本技能是 `ic500-futures-analysis` 的**中长线执行层**，专注于日线级别的趋势判断和 3-10 天持仓方案。与 `ic500-daytrading`（日内短线）形成互补：

| 维度 | ic500-daytrading（日内） | 本技能（中长线） |
|------|--------------------------|------------------|
| 持仓周期 | 分钟-小时 | 3-10 天 |
| 数据重点 | 5min/30min/60min/180min + tick | 日线 MA/MACD/RSI + 日成交量 + OI 多日趋势 |
| 止损宽度 | 20-38 点 | 80-150 点（ATR 基础） |
| 目标幅度 | 30-100 点 | 150-400 点 |
| 核心分析 | 四维趋势裁决 + 盘口验证 | 市场体制分类 + 趋势持续性评估 |
| OI 分析 | 日内 OI 变化率 | 多日 OI 累计变化趋势 |
| 仓位上限 | 2 手 | 2 手（薄流动性 1 手） |

> **必须先加载 `ic500-futures-analysis`** 获取底层数据格式、字段说明与风控铁律。本技能复用其日线数据字段，但不重复底层规则。

## 两种运行模式

### 模式 A：趋势预判模式（盘后 / 开盘前）
**触发词**：「中长线」「波段」「多日持仓」「10天方案」「趋势行情」「是牛吗」「牛市」「熊市」
**产物**：市场体制判定 + 趋势持续性评估 + 3-10 天交易方案 + 入场/止损/止盈/仓位

### 模式 B：持仓管理模式（持仓中）
**触发词**：「持仓怎么办」「加仓吗」「减仓吗」「中长线止损」「波段持仓」
**产物**：持仓健康度评估 + 加减仓建议 + 移动止损 + 时间退出

## 核心流程：五步法

### Step 1：市场体制判定

基于日线 MA 排列、MACD、RSI、布林带、OI 多日趋势、成交量六大维度，判定当前市场体制。详见 `references/market_regime.md`。

**六种体制**：

| 体制 | 核心特征 | 操作方向 |
|------|----------|----------|
| 牛市趋势 | MA 多头排列 + OI 增 + 放量 | 顺势做多 |
| 熊市趋势 | MA 空头排列 + OI 增 + 放量 | 顺势做空 |
| 熊市反弹 | MA60 仍在上 + OI 减 + 缩量涨 | 观望或反弹末端做空 |
| 牛市回调 | MA60 仍在下 + OI 减 + 缩量跌 | 回调到位做多 |
| 震荡区间 | MA 粘合 + MACD 震荡 | 区间两端操作 |
| 转折期 | MA 排列变化 + MACD 交叉 | 等确认再入场 |

**判定优先级**：熊市反弹/牛市回调 > 牛市趋势/熊市趋势 > 震荡区间 > 转折期

**关键判别规则**：
- **OI 是核心鉴别器**：价格上涨 + OI 减少 = 熊市反弹（非牛市）；价格上涨 + OI 增加 = 牛市趋势（真牛市）
- **成交量是确认器**：缩量上涨不可持续；放量上涨才是真趋势
- **MA60 是分水岭**：MA60 在上方 → 长期空头未逆转；MA60 在下方 → 长期多头未逆转

### Step 2：趋势持续性评估

评估当前趋势还能持续多久。详见 `references/trend_analysis.md`。

**六维度评分**（总分范围 -9 ~ +9）：

| 维度 | 权重 | 核心判断 |
|------|------|----------|
| MA 趋势强度 | 25% | 排列方向 + 间距变化 |
| MACD 动能 | 20% | bull/bear + hist 变化 |
| RSI 位置 | 15% | 区间 + 趋势配合 |
| 布林带位置 | 15% | position + trend |
| OI 多日趋势 | 15% | 5日累计变化 |
| 成交量趋势 | 10% | 5日均量 vs vol_ma |

**持续性总评**：

| 总分 | 趋势持续性 | 持仓周期 | 仓位 |
|------|-----------|----------|------|
| >= +6 | 极强 | 10 天 | 2 手 |
| +4 ~ +5 | 强 | 7-10 天 | 1.5 手 |
| +2 ~ +3 | 中 | 5-7 天 | 1 手 |
| 0 ~ +1 | 弱 | 3-5 天 | 0.5 手 |
| -1 ~ 0 | 弱（反向） | 3-5 天 | 0.5 手 |
| -3 ~ -2 | 中（反向） | 5-7 天 | 1 手 |
| -5 ~ -4 | 强（反向） | 7-10 天 | 1.5 手 |
| <= -6 | 极强（反向） | 10 天 | 2 手 |

### Step 3：关键价位识别

基于日线级别识别支撑阻力。详见 `references/price_levels.md`。

**价位类型**：
- **趋势线支撑/阻力**：连接近 10 日低点/高点
- **MA 支撑/阻力**：MA5/MA10/MA20/MA60
- **布林带轨道**：上轨/中轨/下轨
- **前高/前低**：近 10 日内的重要高点和低点
- **整数关口**：每 100 点（如 7800、7900、8000）

### Step 4：交易方案生成

生成包含完整要素的中长线方案。详见 `references/position_management.md`。

**方案模板**：
```
方向：多 / 空
市场体制：[Step 1 判定]
趋势持续性：[Step 2 评分] → 持仓 X 天
入场价：XXXX（当前价 / 回踩价 / 突破回确认价）
止损价：XXXX（ATR 的 1.5-2 倍，或关键支撑/阻力下方/上方 30-50 点）
目标1：XXXX（+150-200 点，减仓 50%）
目标2：XXXX（+300-400 点，清仓）
盈亏比：XX/XX = X.XX（必须 >= 2.0）
仓位：X 手（根据持续性评分 + 置信度）
持仓周期：X 天（根据持续性评分）
时间退出：到期日强制平仓 / 趋势反转信号触发
逻辑链：至少 5 项证据（3 技术 + 1 资金 + 1 风控）
```

### Step 5：持仓管理（多日）

根据持仓天数进行动态管理。详见 `references/position_management.md`。

**多日持仓管理核心**：

| 持仓天数 | 管理重点 | 操作 |
|----------|----------|------|
| 第 1-2 天 | 方向验证期 | 浮亏超 50% 止损 → 方向错误；浮盈正常持有 |
| 第 3-5 天 | 趋势确认期 | 移动止损至保本；浮盈 > 100 点可加仓 0.5 手 |
| 第 6-8 天 | 利润保护期 | 移动止损至入场 + 50 点；达到目标1 减仓 50% |
| 第 9-10 天 | 退出准备期 | 移动止损至入场 + 100 点；评估是否延期或清仓 |

**移动止损阶梯**：

| 浮盈 | 止损位 | 说明 |
|------|--------|------|
| 0-50 点 | 原止损不动 | 给波动空间 |
| 50-100 点 | 移至入场价（保本） | 不亏 |
| 100-200 点 | 移至入场 + 50 点 | 锁 50 点 |
| 200-300 点 | 移至目标1 - 30 点 | 锁大部分利润 |
| > 300 点 | 跟随 MA10，保持 30 点距离 | 移动止盈 |

## 铁律

1. **OI 鉴别铁律**：价格上涨 + OI 多日减少 = 熊市反弹，禁止追多，禁止判定为牛市趋势
2. **MA60 分水岭**：MA60 在 MA5/MA10/MA20 上方时，任何上涨都先视为反弹而非反转
3. **缩量否决**：5 日均量 < vol_ma 的 0.8 倍时，趋势持续性评分降一级
4. **盈亏比底线**：所有方案盈亏比必须 >= 2.0，低于此值不动
5. **证据约束**：任何交易建议必须引用至少 5 个不同类型字段（3 技术 + 1 资金 + 1 风控），否则输出"证据不足，维持观望"
6. **薄流动性约束**：volume_ratio < 0.03 时，仓位上限 1 手，止损宽度增加 50%
7. **趋势反转确认**：体制切换需 >= 3 个维度同时变化，单一维度变化不构成反转
8. **时间退出优先**：到期日（第 10 天）强制平仓，不论盈亏

## 实战验证案例

### 案例 1：2026-07-30 至 2026-08-11 熊市反弹

**背景**：7月30日 IC2609 跌至低点后连续反弹，至8月11日涨幅 +10.8%

**体制判定过程**：
1. MA 排列：MA5 > MA10 > MA20，但 MA60 仍在上方（7964 vs 8171+）→ 长期空头未逆转
2. OI 多日趋势：5日 OI 累计 -10.15%（大幅减少）→ 空头平仓，非新多入场
3. 成交量：5日均量持续低于 vol_ma → 缩量上涨
4. RSI：从 13.4（极端超卖）反弹至 55-65 → 超卖修复型反弹
5. MACD：出现金叉但 hist 仍在正值区边缘 → 动能偏弱

**判定结果**：**熊市反弹**（满足 5/6 项条件）

**趋势持续性评分**：+1（弱）→ 持仓 3-5 天，仓位 0.5 手

**操作建议**：
- 禁止追多（OI 减 + 缩量 = 反弹不可持续）
- 等待反弹衰竭信号后做空
- 反弹衰竭信号：RSI > 70 后回落 + MACD 死叉 + 放量滞涨
- 做空入场：反弹高点附近（7960-8000），止损 8050，目标 7700

**教训**：
- 价格涨 +10.8% 不等于牛市，必须看 OI 和成交量
- 熊市反弹可持续 7-15 天，但幅度有限且随时可能反转
- OI 减少的上涨是"虚涨"，不是真牛市
